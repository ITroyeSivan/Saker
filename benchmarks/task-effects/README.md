# 本地效果基准

提供仅监听 127.0.0.1 的合成靶场、请求审计、独立评分器与实验协议。校准集合包含单次输入变更、身份及票据前置流程、阴性和环境故障，另设保留集合。该集合主要覆盖访问控制与私有文档读取，不能代表所有漏洞类别。

每次运行生成新的身份、对象和标记。代理只接收练习账号、正常请求与业务问题，控制端持有真值和审计。确认要求所有者、主体、越界与匿名拒绝对照；反射、错误页、正常共享、旧回执和代理自报确认不能代替独立证据。

```powershell
node scripts/test-task-effect-benchmark.mjs
node scripts/start-task-effect-lab.mjs --case p1 --out <工作区临时目录>/task-effect-run
```

启动器将代理材料写入 agent/brief.json，审计与评分写入 controller/。标准输入接受 request、grade 和 stop JSON 消息；30 分钟自动停止。共享适配器在执行前检查请求范围与操作额度。

实验须固定模型、工具、身份、快照和预算，按种子随机排序并重复运行。总 token 或人工介入记录缺失时用 null 表示；失败、不可比、超额及未确认结果均须保留。基准检查通过不等同于模型检出率提升。结算后的 token 检查不能作为调用前硬预算保证。

保留集合规格存在控制端源码中，不能视为对开发者不可见的盲测。模型运行目录须隔离控制端源码、真值和审计。
