# 本地效果基准基础

这部分是 G1 的靶场与评分器基础，尚未完成三组模型对照，不能用于声明 Saker 检出率或效率提升。它不改变已经发布的 0.4.93 运行包。

校准集合 24 例：8 个单次输入变更的私有文档读取阳性、6 个登录/身份/导出票据等前置流程阳性、6 个阴性、4 个环境故障；另分出 12 例保留集合。当前以私有读取为主，包含反射、相似错误页、过期身份、缺版本和正常共享。它还不是覆盖各种漏洞类别的完整基准；浏览器执行与内容差异验证需要 G4 扩展后接入。

保留集合的规格存在控制端源码中，不能称为对开发者不可见的盲测。实际模型实验必须只给代理工作目录中的 brief 与共同工具接口，隔离控制端源码、真值和审计；尚未完成该运行适配，因此这里不报告隐藏集合模型成绩。

靶场仅监听 `127.0.0.1`，每次创建新的身份、对象和私有标记。代理只拿合成练习账号、正常请求及业务问题，不拿漏洞标签、私有标记或判分规则。父运行器持有真值与实际请求审计；确认需要两轮所有者、主体正常、越界读取和匿名拒绝对照。请求中的标记反射、200 错误页、正常共享、旧运行回执、重复 ID、篡改正文和代理的“已确认”文字都不能代替效果依据。

环境故障确实触发 503、握手前断连、收到请求后断连与客户端超时。故障回执通过共同控制端 HTTP 适配器捕获，不伪造成功响应。用任意外部 HTTP 客户端直接访问断连案例时，控制端可能无法获得客户端失败回执；没有证据的结果保持未确认。

```powershell
$env:TEMP = (Resolve-Path ../_ref/tmp).Path
$env:TMP = $env:TEMP
$env:TMPDIR = $env:TEMP
node scripts/test-task-effect-benchmark.mjs
node scripts/start-task-effect-lab.mjs --case p1 --out ../_ref/tmp/task-effect-run
```

启动器在 `agent/brief.json` 中保存代理材料，将控制端审计和评分单独保存到 `controller/`。标准输入接受 `request`、`grade` 和 `stop` JSON 消息；30 分钟自动停止。外部客户端只用于 Desktop 接入冒烟，不能冒充同工具对照；共享适配器会在执行前拒绝超预算和越界请求，任意外部客户端的请求另按实际服务器审计计数。

实验协议固定普通 Agent、冻结 0.4.92、新版三个实验组，每例每组三次，顺序按明确种子随机；ARTEX 可选。模型版本、工具及身份摘要、快照与总预算不一致时标记不可比。30 分钟/200 请求/150k token 只是待校准上限；校准未完成的协议不能作为公平成绩。用量缺失时总 token/人工介入显示 `null`，不写成零。

目前通过的是 36 个本地靶场及评分器的行为检查，模型调用数为 0。还需接入真实模型调用记录、子代理共享用量、文件隔离、预算校准、冻结旧版本及完整随机三次运行。正式成绩需保留全部失败和不可比运行。
