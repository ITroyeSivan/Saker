# dsh-tool-scope

把本轮不用的工具声明收起，减少每次模型请求携带的内容。使用宿主的 per-agent tools.restrict({deny})，不修改工具权限。

渗透测试默认保留任务、业务资料、请求对照、证据、成果和知识读取。小问题不默认加载全部资产平台、情报更新器和扫描器，也不开放绕过任务管理的子代理入口。

| 工具包 | 何时加载 |
|---|---|
| task-workflow | 多步依赖、持久队列或中断恢复；含 operation_intent/task 等已有账本工具 |
| asset-discovery | 只给URL时做有限识别，或明确约定的少量资产查询 |
| nday | 查相关公开漏洞、核对组件条件、维护情报源 |
| active-scan | 已选定范围和检查方法，需要相应扫描器 |
| webshell | 历史能力；加载不能解除渗透任务主线的禁用规则 |

模型通过 tool_pack 的 list/load/unload 操作切换。加载前后沿用同一任务和预算；结束收起。工具清单使用当前代理的实际视图，包含预设注入的工具；新挂载的工具在后续消息刷新，已加载包不会被重复隐藏。

旧代码审计、CTF会话仍按原门禁处理，不作为新会话入口。规则失败会显示警告并保留原清单，不能静默制造缺失工具。

本插件只减小声明范围。目标授权、凭证使用、执行和证据检查仍由相应工具控制。是否节省总token要合计主代理和子代理的实际模型用量，工具定义字节下降不能单独证明实战效率。

测试：从仓库根运行 node --import ./scripts/test-stub-register.mjs plugins/dsh-tool-scope/test/run.mjs。桌面验收还须确认默认隐藏、加载可调用、卸载后声明消失以及核心工具保留。
