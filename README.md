Saker 是运行在 [DeepSeek Harness Desktop](https://github.com/deepseek-ai/deepseek-harness) 上的安全测试工作台。它把聊天、测试文档、真实浏览器、请求回执、问题记录和交付整理放在同一个会话里。

你给目标、资料和边界，Saker 负责保存事实、连接工具、限制执行并维护进度。业务判断仍由模型和你完成，程序不会把 HTTP 200、菜单隐藏或一段模型文字冒充漏洞结论。

## 为什么不是另一个聊天壳

| 你真正需要的能力 | Saker 的做法 |
| --- | --- |
| **看懂已有测试文档** | Word、Excel、文本在本地解析并保留来源、修订和真实段落位置；不是只把文件丢进上下文 |
| **连续执行，不用反复催** | 独立检查继续推进，缺账号、缺对象或需要你决定的项单独等待，不会拖住其余工作 |
| **看得见程序做了什么** | 模型调用、工具动作、目标请求、回执、失败和未知结果分别记录；停止后仍能查看和导出 |
| **用真实浏览器处理登录态** | 受管 Chrome for Testing 保持页面、身份和会话，支持观察、点击、输入、上传下载和请求读取 |
| **结论有可复用证据** | 请求版本、身份、正常对照和证据引用一起保存；缺关键证据时停在待验证，不自动晋级 |

## 两种工作起点

### 按文档测试

在聊天顶部选择 **按文档测试**，添加测试要求后开始。适合公司内部项目、验收清单、客户提供的测试说明和需要按原文逐项核对的场景。

1. 文档先在本地完成解析，显示可读段落、位置和解析警告。
2. 模型读取来源后，把要求、参考材料和不可读区域分别整理。
3. 每个检查按实际工具回执记录结果、已测内容和缺口。
4. 所有来源处理完且检查结束后自动收尾；只有缺条件项时显示等待，不伪装完成。
5. 报告、检查表和来源清单从同一份已保存事实导出，不会重新访问目标。

### 实战挖掘

从一个具体问题开始，例如“普通账号能否读取其他人的订单”。常规测试、Nday 发现和 0Day 挖掘共用站点、身份、请求与资料记录。

## 从资料到交付

| 阶段 | 你能看到什么 |
| --- | --- |
| 添加资料 | 文件、请求、HAR、curl、JS 和扫描结果按类型保存；查看不等于模型已读 |
| 开始任务 | 明确目标、允许访问的范围、排除路径、速率、额度和协作方式 |
| 连续检查 | 当前检查、已完成内容、关键缺口、身份与目标请求回执 |
| 复核结果 | 正常对照、异常观察、方法版本、对象归属和待补证据 |
| 导出交付 | Markdown 报告、检查表、来源清单和证据包使用同一套结果视图 |

## 真实浏览器与工具

浏览器操作固定使用独立 Chrome for Testing，不用一次性 HTTP 探针代替登录后的页面流程。浏览器目录可在 **应用设置 → 安全配置 → 工具** 中修改。

目标请求优先走受管浏览器或 Saker 的可计量请求入口；命令行 curl 不作为默认验证方式，因为它容易漏掉浏览器自动添加的头、Cookie、重定向和实际页面状态。

已配置的 Burp、Yakit 和其他 MCP 服务可继续使用。MCP 工具可调用、服务在线和某个业务结论成立是三件不同的事，界面会分别显示。

## 结果不是一句“已完成”

- 已确认问题、未发现问题、需进一步确认、缺少条件、不适用和未开始分别显示。
- `needs_check` 和部分完成保留实际缺口，不计入完整阴性。
- 请求正文可读取、可续读；超时、断线、截断、二进制和未保存明确区分。
- 停止任务会保留资料、回执和当前结论；恢复前重新核对环境、身份和范围。
- 子代理和后台辅助调用计入同一轮成本记录；看不到的传输不会被声称已经计量。

## 安装

当前版本 **0.4.111**，适用于官方 Windows Desktop **0.2.1-rc.2**，同时兼容 **0.2.0-rc.2**。

1. 安装官方 Desktop，完成初始化和模型配置，然后完全退出应用。
2. 下载 `Saker-0.4.111-desktop.zip`，解压到长期保留的目录。
3. 在解压目录打开 PowerShell：

```powershell
node scripts/install-desktop.mjs --desktop-dir "C:/path/to/DeepSeek Harness"
```

安装器会调用官方桌面命令，在一个事务中安装 20 个包，并保留原来的用户数据、会话、插件选择和 MCP 配置。更新后从桌面的 **Saker (dsh Desktop)** 快捷方式启动，不需要记命令行。

需要 Node.js 22.5 或更高版本。详细升级、Web profile、回退和卸载步骤见 [安装说明](docs/getting-started.md)。

## 项目状态

Saker 仍在快速迭代。当前适合个人学习、本地实验和已获授权的安全测试，不建议未经验证直接投入真实业务处置。

扫描器和模型都可能误判；涉及真实系统的处置应由安全人员复核。配置和任务产物可能包含 Token、Cookie、请求报文和源码，公开日志或截图前请脱敏。
