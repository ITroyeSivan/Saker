# Saker 0.9.31

### ✨ 新增功能

- 新增统一设计系统：字号、间距、圆角、边框、阴影、控件高度和语义状态色集中管理。
- 聊天工具条统一为“方法 / 能力 / 状态 / 说法 / 资料 / 更多”，更多菜单改为两列快捷操作。
- 工作台仪表盘改为“最近任务 + 需要你处理”两栏；待办只展示前 4 条。
- 测试结果页、设置抽屉、能力库、角色库、知识库和两张图统一列表、卡片、标签和详情层级。

### 🐛 问题修复

- 修复设置抽屉左侧分类文字重叠、面板过高被顶部裁切的问题。
- 修复仪表盘任务结果列溢出卡片的问题。
- 修复模块分类在窄容器换行后孤立一行的问题，改为横向滚动筛选。
- 修复方法入口显示“直接处理”导致用户不知道这是方法设置的问题。

### 🎨 体验优化

- 聊天首屏场景卡改为轻量卡片，减少粗边框和无效留白。
- 统一正文 13px、次要 12px、标签 11px、标题 16px；不再混用多套字号。
- 按钮 32px、输入 32/36px、卡片 12px 圆角；表格行高 40px。
- 图表节点标题使用省略号，完整标题进入详情；画布不再横向裁切。
- 页面标题增加范围副标题，减少“只有一个大标题”的空洞感。

### ⚠️ 其他变更

- `@dsh-external/dsh-redteam-results` 升到 `1.4.24`，根包 `0.9.31`。
- 不改变用户数据、MCP、会话、知识和个人方法；未发布、未 push、未提交 Git。
