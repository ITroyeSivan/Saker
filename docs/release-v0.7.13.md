# Saker 0.7.13

本版把候选成果的独立复核接到官方 Desktop 的现有有界子任务上。

### ✨ 新增功能

- 成果详情新增“请助手复核”；只在存在候选、用户主动点击时运行。
- 复核使用现有 `purposeTasks`：继承父任务范围、预算、停止和共享名额，不新建平台或模型循环。
- 复核输出显示在候选条目下，不自动改写成果状态；确认/否定仍由证据和人工复核决定。

### 🐛 问题修复

- 协作人数为 0 时明确提示先启用“多助手”，不静默发请求。
- 父任务已停止、会话不可用或宿主缺少启动生命周期时，返回具体原因并保留原候选。
- 证据引用现在按 `request`、`asset`、`execution`、`browser`、`source`、`file` 分别核验；已存在的当前会话请求不再被误判成缺失文件。

### 🎨 体验优化

- 复核按钮只在候选详情出现，不占用默认会话区。
- 复核结果留在对应候选下，关闭或切换页面后不会把另一个候选的结果串过来。

### ⚠️ 其他变更

- 第二段的组件 Nday/安全变化生产链仍需继续实现；本版不冒充完成。
- 不发布、不 push、不提交 Git。
