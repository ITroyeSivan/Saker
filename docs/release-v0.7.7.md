# Saker 0.7.7

本版继续完善知识检索和日常使用体验。

### ✨ 新增功能

- 支持更自然的中文、英文和混合语言知识查询。短查询保持精确匹配，较长问题会按有效概念排序，不再因为一两个连接词而查不到内容。
- 常见安全缩写、产品名和中文术语可以互相对应，例如 K8s 与 Kubernetes、Log4Shell 与 Log4j、提权与 privilege escalation。

### 🐛 问题修复

- 修复 Markdown 代码块中的 `#` 注释被误识别为章节标题的问题，避免命令示例把文档切碎。
- 修复自然语言问句需要每个词都命中才有结果的问题，相关章节会出现在前五条结果中。
- 跳过文档头部的 YAML 信息，减少无标题正文造成的无关命中。

### 🎨 体验优化

- 新会话保留三张场景卡，首次使用可以直接选择“测一个网站”“审查一段代码”或“解一道比赛题”；点击只会填入输入框，不会自动发送。
- 设置、协作、附件和模板面板继续使用任务语言，并保留跳过配置直接开始的入口。
- 知识查询关闭时不会打开索引、缓存或正文；查询过程中关闭或改变策略时，迟到结果不会覆盖新状态。

### ⚠️ 其他变更

- 需要 Node.js 24.9 或更高版本；当前适配官方 Desktop 0.2.2-rc.1。
- 本版不发布、不 push、不提交 Git。
