# Saker 0.7.10

本版补齐方法证据的时效、代际和身份条件，防止历史回执冒充“本次重新执行”。

### ✨ 新增功能

- 方法步骤新增“必须本次新执行”和“允许复用历史材料”两种证据条件。
- 方法编辑器可限制回执必须属于指定账号；回执缺少身份或不匹配时明确拒绝。
- 执行步骤会记录证据代际、实际采集时间、身份和目标，后续分析可复用同一份历史材料。

### 🐛 问题修复

- 早于本次运行创建的浏览器或 HTTP 回执不能再完成“本次新执行”步骤。
- 旧请求代际、身份不匹配、未来时间、完整性失败或目标不匹配的回执均不能推进。
- “允许复用历史材料”只接受完整、可追溯的回执，不要求它仍属于当前请求修订。
- 同一份历史回执可继续供多个分析步骤使用，不会被全局去重误伤。

### 🎨 体验优化

- 阶段图和步骤预览直接显示“需本次真实回执”或“可复用历史回执”。
- 浏览器执行回执保存发起时使用的身份引用，便于与方法要求核对。

### ⚠️ 其他变更

- 当前仍只支持 2–12 步线性方法；自由分支、循环和任意拖拽重接未实现。
- 对比实验继续暂停；历史记录不复用为新版结论。
- 本版不发布、不 push、不提交 Git。
