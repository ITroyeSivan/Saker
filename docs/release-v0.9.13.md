# Saker 0.9.13

### ✨ 新增功能

- 无新增模型工具；本版只修界面字号。

### 🐛 问题修复

- Saker 主界面、任务详情、测试结果页、方法/设置/资料面板，以及 Hunter、MCP Studio、模式选择等产品页，不再把正文写死为 13/14px。
- 正文读取宿主的 `--dsh-content-font-size`，次要说明读取 `--dsh-content-font-size-secondary`；用户调整「设置 → 字体大小」后，Saker 面板会一起变化。
- 修复“聊天气泡很大、Saker 面板很小”的字号割裂，也避免再次出现过大的统一放大。

### 🎨 体验优化

- 共享 UI kit 的徽标、提示和空状态同步使用宿主次要字号。
- 不修改 Windows 显示缩放，不强制进程级缩放；宿主原生会话区域保持不变。

### ⚠️ 其他变更

- 根包升级到 `0.9.13`；结果插件 `1.4.10`，Hunter `1.6.3`，MCP Studio `1.2.16`，模式选择 `1.1.10`。
- 导出 HTML 报告保留自己的打印字号；全屏攻击面地图的画布标签仍使用固定小字号。
- 不改变数据、MCP、会话、知识与个人方法；不发布、不 push、不提交 Git。
