# Saker 0.9.4

本版修正 Windows 高 DPI 下整个 Desktop 界面过大的问题。

### ✨ 新增功能

- 启动器新增高 DPI 自动上限：Windows 显示缩放高于 150% 时，以 150% 等效缩放启动 Saker Desktop。
- 启动配置支持 `interfaceScale` 手动覆盖，设为 `0` 可关闭自动上限。

### 🐛 问题修复

- 当 Windows 显示缩放高于 150% 时，Saker Desktop 的有效界面缩放自动上限为 150%。
- 修复 200% 缩放下宿主侧栏、会话正文、插件页和工作台字号整体过大的观感。
- 缩放只作用于当前 Desktop 进程，不修改 Windows 显示设置，也不影响其他应用。

### 🎨 体验优化

- 字体仍使用系统 DPI 渲染，保持清晰，不通过位图放大压缩界面。
- 高 DPI 下获得更大的可用工作区，窗口最大化后能看到更多任务和列。

### ⚠️ 其他变更

- 根包版本升级到 `0.9.4`；插件包版本和数据格式保持不变。
- 对比实验继续暂停；0.7.6 的历史结果仍为双方 64/72、McNemar p=1.0，没有成功率优势。

### ⚙️ 配置

- 启动器配置可显式写入 `interfaceScale`（例如 `1.5`、`1.25` 或 `2.0`）覆盖自动上限。
- 将 `interfaceScale` 设为 `0` 可关闭本启动器的缩放覆盖。

### ⚠️ 边界

- 本版只调整 Saker Desktop 的启动缩放，不改变操作系统显示设置。
- 对比实验继续暂停；0.7.6 的历史结果仍为双方 64/72、McNemar p=1.0，没有成功率优势。
- 不发布、不 push、不提交 Git。
