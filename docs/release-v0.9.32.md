# Saker 0.9.32

### ✨ 新增功能

- 模块完成必须附带可解析的 receipt/material/finding/work 引用；不存在、跨任务、完整性失效或重复引用会被拒绝。
- 排队角色使用持久队列 ID 与实际 generation，不再伪造 `queued-*` Host childId；释放名额后才启动。
- 探索图的 Finding 证据统一解析 `evidenceRefs`，request 引用会映射到真实回执后生成 `supported-by` 边。

### 🐛 问题修复

- 全局发现、流量、工作、尝试、发现与回执不再使用 500/100/80 前置截断。
- 未知命令跨页面/刷新保留非敏感恢复指针；重新提交相同意图时先查询原 commandId，并只从 Host 服务端恢复结果。
- `roots.detail` 改为纯读，不再在浏览详情时写入业务根或代际投影。

### 🎨 体验优化

- “适合视图”按实际画布尺寸计算缩放和平移。
- 搜索覆盖完整图数据，可展开并定位当前未显示的节点。
- 支持只看选中节点邻域；大图按列换行，避免单个 20k 像素高列。
- 移除强制 11/12/13px 覆盖，正文与次要文字恢复宿主字号 token。
