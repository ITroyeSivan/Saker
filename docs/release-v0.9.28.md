# Saker 0.9.28

### ✨ 新增功能

- 无新增工具或入口；本次只调整已有界面配色。

### 🐛 问题修复

- 修正浅色背景下中危数字、状态数字和徽标使用柠檬黄导致对比度偏低、观感突兀的问题。

### 🎨 体验优化

- 等级色去掉刺眼的柠檬黄：中危统一改为暖橙色 `#c2650a`（深色看板用 `#ffb454`），在浅色背景上更耐看、对比度更稳。
- 「发现统计」的中危数字、结果徽标、导出报告、时间线/云路径/CTF 待定状态和深色台账看板使用同一套颜色，不再出现一处橙一处黄。
- 提醒条与提示词标签的黄色边框改为低饱和暖棕 `#b45309`，保留“需要注意”的语义但不抢视线。
- 其它等级（严重、高危、低危）和通过/失败状态色不变。

### ⚠️ 其他变更

- 结果插件 `1.4.22`，根包 `0.9.28`。
- 不改变用户数据、MCP、会话、知识与个人方法；未发布、未 push、未提交 Git。
