# Saker 0.9.0

本版把会话内的紧凑入口接到一个完整的安全工作台，同时补齐 rc.2 子代理桥接、角色快照/工作 CAS 和跨会话执行回执复制。

### ✨ 新增功能

- 主内容区新增 Saker 安全工作台，侧栏保留一个入口；进入后按“总览 / 任务 / 发现 / 流量 / 资产与材料 / 测试方法 / 角色定义 / 工具与模型 / 待处理 / 运行记录”浏览。
- 任务内部使用“总览 / 执行 / 探索链路 / 发现 / 资产与材料”五页，任务、发现、回执、材料、方法和角色来自同一读模型。
- `workbench.query` 与 `workbench.command`：页面不另起后台，命令带 `commandId`，同 ID 重复提交返回原结果，不同内容拒绝。
- 工作台可直接暂停/恢复/停止/明确继续任务，提出工作、写指导、局部停止、定义本轮角色、选择方法和发起明确复测。
- 官方 dsh rc.2 子代理激活参数展平桥接：顶层 `parent/prompt/maxDepth/agentOptions`，按精确 activation 释放，不再依赖旧 `drainChildren`。
- 角色定义同版本不可覆盖；同一执行内容重试幂等返回，不同内容必须新版本。
- 工作项更新支持 `expectedRevision` CAS，已停止/完成的工作不能原地复活。
- 子角色启动/续跑复制父任务上下文时，一并复制被引用的宿主执行回执；缺回执明确失败，不要求模型反复重试。

### 🎨 体验优化

- 工作台正文 13–14px、表格行 44px、窄窗自身导航折叠，支持 125%/150% 与亮暗主题；不重画宿主会话、模型和权限区。
- 总览只显示真实任务、发现和待处理；没有数据时显示空态，不伪造零结论。
- 探索链路和资产覆盖使用真实引用；点击任务、发现、方法或角色进入对应详情。

### 🐛 问题修复

- 修复角色同版本被静默覆盖。
- 修复工作项陈旧 revision 仍可写入、stopped 可被改回 active。
- 修复子角色复制父上下文时因跨会话找不到执行回执而要求重试。

### ⚠️ 其他变更

- 结果插件升级到 `1.4.0`，新增工作台控制表与命令记录；旧任务、发现、材料、回执和角色数据继续读取。
- rc.1 与 rc.2 共用同一套桥接入口；rc.2 使用展平激活参数，rc.1 仅在迁移/回滚期间保留旧参数包装。
- 对比实验继续暂停，不新增模型、搜索或评测服务。

### ⚠️ 边界

- 工作台方法编辑当前仍是 2–12 步线性方法；任意循环、自由分支和脚本控制流明确拒绝。
- 公开上游研究仍受闭源、别名、回补和外部 API 可用性影响，缺映射时返回 unknown。
- 原生“停止生成”与受管根终态的统一拦截尚需在 rc.2 Desktop 上继续核对；未通过前不宣称原生入口全部收口。
- 对比实验继续暂停，旧 0.7.6 结果不用于本版优势结论。
- 不发布、不 push、不提交 Git。
