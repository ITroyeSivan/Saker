### ✨ 新增功能

- 在“进度与发现”中集中查看本轮任务、发现、报告和复现文件。

### 🐛 问题修复

- 修复旧 HTTP 验证记录可能一直有效的问题；超过 15 分钟的记录需要重新验证。
- 自动验证、桌面人工复核、成果统计和导出统一检查执行证据时效，重新审阅不能刷新旧回执的时间。
- 缓存任务读取时重新核对证据时效，并显示需要重新取证的原因。

### 🎨 体验优化

- 历史记录继续保留；验证过期后显示“需重新验证”，不会自动重发请求。
- 合并任务与成果、项目工作台入口，优先显示已确认和待验证的问题、测试目标及停止原因。
- 缩小标题和间距，发现记录可直接展开查看请求和响应，用量及子代理详情按需展开。
- 简化功能说明、状态提示和插件介绍；技能和方法设置使用直接的操作说明，自定义提示词编辑区默认收起。
- 文件页标明工作区共享范围，Nday 候选验证记录保留在执行记录中；未登记完成要求时不再显示全部完成。

### ⚠️ 其他变更

- 适用于官方 Windows Desktop 0.2.0-rc.2；更新沿用原有用户数据与 MCP 配置。
