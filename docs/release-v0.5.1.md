Saker v0.5.1 汇总了 v0.4.113 之后的完整调整：从目标、材料或具体问题直接开始，由模型选择方法；Saker 负责浏览器与工具接入、任务控制、执行记录和结果整理。新会话分为“自由测试”和“按文档测试”，常规测试、Nday 发现与 0Day 挖掘保留为研究重点，不再绑定固定步骤。

### ✨ 新增功能

- 新增“自由测试 / 按文档测试”场景入口。自由测试可直接使用受管 Chrome for Testing，无需先建立项目检查表。
- 起始范围支持多行 URL、域名、通配子域、IP、IPv4 CIDR 和资产清单，保留 URL 路径、参数与排除项。
- 自由测试可直接执行普通探索，自动保存实际请求、响应和入口；不再要求每次请求先登记方法或研究方向。
- 新增浏览器人工接管：保留同一页面和身份，暂停模型派发；用户操作后先重新观察，再继续原任务。
- 同一任务支持调整研究重点、范围、协作方式、助手人数与可选预算。聊天中的扩大范围、提额或权限变更先确认，再沿用原任务与累计记录。
- Chrome for Testing 路径可在“安全配置 → 工具”中指定；带外验证统一放入扫描工具入口。

### 🐛 问题修复

- 修复多行 URL、裸域名和 CIDR 的范围解析；严格 HTTPS、指定端口和排除项在助手派发时仍然有效，模型保存的资产标记不会扩大用户范围。
- 修复任务结束一轮后无法正常继续、继续时重建任务或重置累计用量的问题；父任务调整范围后，助手沿用最新限制。
- 修复 FOFA 被动查询被目标访问开关或扫描额度误拦截的问题；保留原查询、过滤、结果数量、分页游标和未完成原因。
- 修复已保存的 HTTP 回执详情和部分项目详情无法读取的问题，保留响应原文与敏感字段遮蔽。
- 完善项目测试中断恢复、浏览器身份与页面状态记录；结果未知的写操作先核对，避免直接重复执行。
- 修复自定义浏览器路径解析、桌面重复启动与旧启动凭据积累造成的启动异常。

### 🎨 体验优化

- 聊天输入区收拢为场景、添加文件、写提示词和设置；研究方向、询问时机、汇报频率与助手设置集中管理。
- 提示词示例支持需求搜索、关键信息填写、直接编辑、复制和插入；模板不作为每轮强制执行的长流程。
- 取消固定操作次数、时长及默认零扫描额度，改为用户按需设置；研究方向不再锁定工具、执行顺序或助手对象。
- 按场景加载相关工具，减少无关声明；项目文档采用有界批量读取，减少零碎调用并保留来源位置与覆盖记录。
- 完善检查表、来源、发现、附件和历史运行的归档与离线导出，兼容旧任务归档。
- 任务状态直接显示范围、资产、进度、待确认项与用量；查看资产、暂停等本地操作不调用模型。
- README 重新组织使用场景、真实界面、提示词、浏览器接管与安装说明，更新过时主图并补充多图介绍。

### ⚠️ 其他变更

- 移除公共知识库、Nday 资料库、采集雷达和固定方法编排的运行入口及安装依赖。CVE、公告、仓库和用户材料由任务按需读取。
- 升级保留旧会话、项目材料、账号、模型和 MCP 配置；不自动删除原有资料。由安装器处理退役插件，并刷新桌面快捷方式。
- 适用于官方 Windows Desktop 0.2.1-rc.2，同时兼容 0.2.0-rc.2；浏览器使用独立 Chrome for Testing。
- 正在快速迭代，目前仅供个人学习与授权实验，暂不建议用于生产环境或正式项目交付。
