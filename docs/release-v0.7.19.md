# Saker 0.7.19

本版修正任务范围建立顺序：本地读代码或读取组件记录，不会再先创建一个“没有目标”的任务，导致之后真正的目标请求被拒绝。

### ✨ 新增功能

- 安全变化链路可以记录可信本地仓库的修复提交、版本、改动文件与变更摘要。
- 任务范围由第一个带目标地址的动作建立；本地 git 读取、组件观察、资料读取不提前创建任务。

### 🐛 问题修复

- 修复“先执行 git show，再请求目标”时任务目标为空的问题。
- 第一个真实请求会以自己的授权地址建立范围；范围外请求仍被拒绝。
- 组件事实/公告读取不再改变任务范围。

### 🎨 体验优化

- 任务详情会显示真实的目标回执、组件适用性和候选结果。
- 漏洞版/修复版对照与目标请求分开记录，不把本地对照当成目标结论。

### ⚠️ 其他变更

- 本地复现成立不等于目标受影响；没有 CVE 不称 0day，候选仍待独立复核。
- 不发布、不 push、不提交 Git。
