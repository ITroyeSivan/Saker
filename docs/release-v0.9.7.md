# Saker 0.9.7

本版恢复 Windows 默认显示比例，不再自动压到 150%。

### ✨ 新增功能

- 启动器默认不传任何缩放参数，完全跟随 Windows 显示设置。
- `interfaceScale` 仅作为显式手动覆盖，适合确实想改变 Saker 比例的少数用户。

### 🐛 问题修复

- 修复 200% 系统缩放被启动器强制改成 150% 后，用户觉得字变小的问题。
- 启动器不再读取 `AppliedDPI`，也不会自动改写应用缩放。

### 🎨 体验优化

- 默认观感与官方 Desktop 其他界面保持一致。
- 不修改 Windows 设置，不影响其他应用。

### ⚠️ 其他变更

- 根包升级到 `0.9.7`；结果插件、任务数据和模型准入逻辑保持 0.9.6 版本。
- 对比实验继续暂停；0.7.6 的历史结果仍为双方 64/72、McNemar p=1.0，没有成功率优势。

### ⚠️ 边界

- 手动 `interfaceScale` 是进程级覆盖，不是系统缩放设置。
- 不发布、不 push、不提交 Git。
