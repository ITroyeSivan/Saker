# Saker 0.7.1

本版重做聊天输入区上方的主要面板，目标是让第一次使用的用户知道“现在能做什么”，而不是先读实现说明。设置、协作、资料、参考资料和场景选择都改成任务语言，并保留原有数据与执行语义。

### ✨ 新增功能

- 输入框上方只保留一个场景选择器，固定入口为「协作 / 添加资料 / 提示词 / 任务设置」。
- 场景说明改为“我有目标，边测边看”“按题目和附件解题”“按测试要求逐项检查”。
- 任务设置改为左侧分组导航：测试范围、参考资料、用量与节奏；高级权限和诊断收进折叠区。
- 设置页直接提供“开始任务与预算”，不再把预算向导藏在不可见的旧面板里。
- 参考资料改为左右双栏：左侧搜索与资料列表，右侧直接阅读正文；不再显示内部索引编号。
- 协作面板改为“团队协作”，空状态明确说明当前没有子任务，保留运行中助手的单独停止。

### 🎨 体验优化

- 设置项按用户动作组织，先写授权范围、再决定是否访问网站和分配用量。
- 知识查询状态显示为“已开启 / 已关闭”和三种中文策略，不再暴露 `web-first` 等内部值。
- 资料导入保留文件选择、粘贴和排队；进度只在导入时出现，完成后显示结果摘要。
- 未设置的可选额度统一显示“未设置”，留空表示沿用宿主限制。
- 删除隐藏的旧设置树，避免同一页面存在两套表单和两套保存语义。

### 🐛 问题修复

- 修复设置抽屉里的预算输入没有传给“开始任务”面板的问题。
- 修复搜索设置项后切换到目标分组仍找不到字段的问题。
- 修复删除旧设置树后“存为新任务默认”和开始任务入口丢失的问题。

### 🔐 边界

- 本版没有执行真实模型与裸 dsh 的 A/B 对比，也不宣称效果领先；现有证据只覆盖自动执行与 Desktop 操作检查。
- 未发布、未提交 Git；安装包与校验值以交付文档为准。
- 外部 Burp / Yakit 未启动时仍显示未连接，不会伪造可用工具数量。

### ⚠️ 其他变更

- 需要 Node.js 24.9 或更高版本；当前适配官方 Desktop 0.2.2-rc.1。
- 更新沿用原有会话、账号、个人模板、任务历史、MCP 配置和日常 user-data。
