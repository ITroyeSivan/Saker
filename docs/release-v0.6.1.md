# Saker 0.6.1

本次汇总自 **0.5.1** 以来的全部更新：统一自由测试、案例测试和比赛模式，让模型直接研究，程序保存实际执行与结果，并集中改善连续对话、协作和检查表体验。

### ✨ 新增功能

- **新增比赛模式**：围绕题面、附件和实例解题，按题保存文件、候选答案与执行记录，支持本机命令和本地 Docker 环境。
- **比赛进程交互**：每次执行独立保存 stdin、stdout、stderr 和状态，支持长输出续读、向交互进程写入及主动停止。
- **可选离线资料**：比赛本地资料默认关闭，启用后按需检索和分段读取；题面与用户附件始终可读。候选答案与通过状态分离，由用户或平台确认。
- **统一三场景入口**：自由测试、案例测试、比赛模式共用一个选择器，保留各自草稿与设置；切换运行中的任务时明确处理原任务。
- **自动保存实际执行**：从命令、请求、浏览器、文件和工具返回中保留依据与可见答复，模型不必另行登记或补录。
- **按需助手与模型选择**：主模型直接工作，独立调查、复核或整理报告时再使用助手；助手继承任务范围、身份与共享预算，并自动交回结果。
- **案例检查表与历史**：从项目文档形成检查项，集中查看要求、执行情况、结论和说明，支持历史查看、选中项重测及完整材料导出。

### 🐛 问题修复

- 修复新会话发送首条消息前，提示词示例无法打开、设置不可编辑及场景名称显示不一致的问题。
- 修复普通回答结束后，完整的后续要求不能继续执行的问题；补充账号、调整重点或指定下一步时保留原任务和累计用量。
- 修复助手缺少命令、文件等必要能力，以及题面、附件、账号身份或模型预算未正确继承的问题。
- 修复 Excel 表头误识别、首条要求丢失、长清单遗漏、隐藏区域选择和来源归属问题。
- 修复暂停后的返回、重试与历史执行关联，避免旧失败覆盖新结果、迟到返回混入新一轮，或恢复任务误控制原进程。
- 修复显式身份不存在时降级为匿名请求、账号与请求认证冲突不清晰的问题。
- 修复修改额度重置已用量、停止后仍派发新操作，以及本地模型服务并发控制问题。
- 修复案例进度不自动更新、归档后历史入口消失、切换历史时误操作旧记录及导出对象错误。
- 修复长输出、普通答复和交付材料的遗漏或截断提示，保留完整可导出的原文与来源。

### 🎨 体验优化

- 检查表改为限宽、限高的弹窗；长说明先显示短预览，详情独立滚动，聊天输入区保持可用。
- 结果集中到执行记录、发现的问题和测试资料，查看已有记录不增加模型调用。
- 按场景缩小常驻工具列表，替换过期运行快照，避免重复堆积相同状态。
- 设置草稿按会话保留，保存失败显示具体错误；比赛模式只展示当前支持的设置。
- 更新提示词示例与三场景使用说明，支持修改关键信息后复制或插入，内容由用户决定。

### ⚠️ 其他变更

- 支持官方 DeepSeek Harness Desktop **0.2.1-rc.5**，保留 **0.2.1-rc.2、0.2.0-rc.2** 兼容；安装包包含 15 个产品插件和根包。
- 升级安装会移除旧比赛观察器及后台自动纠偏插件，保留用户历史、账号、个人模板、浏览器与 MCP 配置。
- Docker 使用本地已有镜像，不自动拉取；安装后请保留发布包解压目录，尤其是 `dist/desktop`。
- 项目正在快速迭代，仅供个人学习与授权实验，暂不建议用于生产环境或正式项目交付。
