### ✨ 新增功能

- 无新增功能。

### 🐛 问题修复

- 任务取消或超过时间额度后，即使没有设置模型调用上限，也会拒绝新的模型调用。
- 子任务取消或超时只停止该子任务，不会错误地使父任务的共享模型额度失效。
- 模型调用在计数前和发出前检查停止状态，取消尚未发出的预留。

### 🎨 体验优化

- 主任务与子任务统一遵守停止条件，减少停止后产生的额外模型消耗。

### ⚠️ 其他变更

- 适用于官方 Windows Desktop 0.2.0-rc.2；更新沿用原有用户数据与 MCP 配置。
- 模型调度次数额度不等同于严格 token 总预算，完整严格 token 预算目前不可用。
