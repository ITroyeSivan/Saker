# Saker 0.7.4

> 历史版本。0.7.5 已修复 0.7.4 复核发现的 H01–H04 迁移问题，当前说明见 `release-v0.7.5.md`。

本版处理 0.7.3 复核发现的边界问题：同工作区草稿隔离、旧会话键升级、读取版本一致性、长元数据裁剪、worker 故障降级和整理交互。

### ✨ 新增功能

- 旧版会话键下的知识条目、比赛资料和整理草稿会在升级时按可信会话映射到当前工作区；原会话仍可读回。
- 资料读取游标绑定文档修订和章节；旧库 ref 校验当前 sha1，内容替换后要求重新搜索。
- 整理按钮旁预取并显示实际模型与本地/云端去向，主按钮仍保持一次点击发起。

### 🐛 问题修复

- 修复同一工作区内不同根会话仍可读取或修改彼此未保存整理草稿的问题。
- 修复工作区键升级后旧索引、旧比赛资料和旧草稿失去访问的问题。
- 修复 sourceId 续读和旧库 ref 不校验内容版本、可能拼接两版正文的问题。
- 修复长标题/来源仍能把唯一真实命中裁成空行、却保留 `status=hits` 的问题。
- 修复本地检索 worker 失败后退回宿主同步扫描、导致取消与超时失效的问题；现在明确返回可重试错误。
- 修复 `installCurationStyles()` 未把样式表挂到 `document.head`，导致整理弹层没有遮罩、背景和完整布局的问题。

### 🎨 体验优化

- 整理弹层恢复独立遮罩、边界和内容区滚动；操作栏在底部吸附，1279×820 与 800×600 下四个按钮均完整可见。
- 整理说明与实际行为一致：点击一次立即发起，并在按钮旁显示模型/去向，不再声称还有第二次发送确认。

### ⚠️ 其他变更

- 需要 Node.js 24.9 或更高版本；当前适配官方 Desktop 0.2.2-rc.1。
- 本版未执行真实付费模型 A/B，不宣称效果领先。
- 本版未发布，也未提交 Git。
