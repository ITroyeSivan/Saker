# Saker 0.9.6

本版补齐模型服务的跨进程并发租约，并保留 0.9.5 的工作租约、助手名额和命令幂等修正。

### ✨ 新增功能

- 模型服务并发 gate 增加 SQLite `model_service_leases`，同一本地 provider 的并发上限不再只是进程内 Map。
- 租约记录 owner PID；活进程的租约不会被第二个 Desktop 进程抢走，死进程租约会在下一次准入时清理。

### 🐛 问题修复

- 修复两个 Desktop 进程各自按同一 provider 并发上限放行、合计超出限制的问题。
- 修复进程退出后模型服务租约永久占位的问题。
- 修复排队等待期间取消请求仍残留 abort 监听的问题。

### 🎨 体验优化

- 持久化 gate 只使用本地结果库，不新增网络调用或常驻轮询。
- 等待中的模型请求仍可被任务停止或取消信号中止。

### ⚠️ 其他变更

- 结果插件升级到 `1.4.5`；模型预算、任务策略和历史会话保持兼容。
- 对比实验继续暂停；0.7.6 的历史结果仍为双方 64/72、McNemar p=1.0，没有成功率优势。

### ⚠️ 边界

- 本版约束的是同一结果库上的本地 provider 并发；远端服务自身的限流仍以实际返回为准。
- 不发布、不 push、不提交 Git。
