# Saker 0.4.93

多步任务可登记前置任务和固定哈希的产物条件。宿主只领取就绪任务，前置未完成时拒绝启动并显示等待原因；稳定任务键避免重复登记，执行租约拒绝旧执行者提交。没有依赖的历史任务保持原语义。

渗透模式通过 `tool_pack load task-workflow` 按需加载任务工具。修复 Desktop 项目工作台空 JSON 响应、工具 schema 导致插件激活失败，以及本地账本操作被预算守卫误拦的问题。

官方 Desktop 实际跑通“等待→前置产物登记→领取→完成”，标准回归 86 套、13,607 项通过、0 失败、16 跳过，并完成六种机制回退的反向验证。适合学习和有人监督的使用；这批不是漏洞检出率或高并发性能验证。
