### ✨ 新增功能

- 「设置 → 漏洞情报更新」支持订阅公开 GitHub 仓库，仅同步或同步后由默认模型整理为待复核知识。
- 增量采集保留来源提交、正文摘要和原文依据，提供每轮/滚动日限额、失败重试与积压状态。

### 🐛 问题修复

- 修复模型服务依赖未注册导致整理失败、以及不兼容依赖声明导致接口未注册的问题。
- 空响应增加中文诊断，避免直接显示 Unexpected end of JSON input。
- AI 返回原文片段编号后由程序回填引用，并继续校验产品、版本和依据。

### 🎨 体验优化

- 正文未变的已整理条目不重复调用模型；停止订阅保留历史与用户编辑。
- 整理结果可进入研究知识检索；失败输出保留诊断，不自动发布为知识。

### ⚠️ 其他变更

- Windows 官方 Desktop 0.2.0-rc.2 实测同步 194 文件；最终三篇整理 2 篇发布并可检索、1 篇失败待重试。这是小样本通路验证。
- 83 套标准回归、13,577 通过、0 失败、16 跳过；MCP 配置保留但两个服务未连接。
- 整理不执行来源代码，不自动生成已确认漏洞或可执行探针；今天同步不代表来源仓库今天更新，尚缺无人值守生产效果证据。
