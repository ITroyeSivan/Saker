# Saker 0.9.1

本版调整 Saker 自有界面的字号与行高，让工作台在系统高缩放显示器上保持紧凑、可扫读；宿主原生会话区域不变。

### ✨ 新增功能

- 共享字号令牌加入 11px，用于任务表、导航和工具型密集列表。

### 🐛 问题修复

- 修复 Saker 工作台、任务详情、方法编辑器和提示词面板在系统 200% 缩放下字号偏大、行距过松的问题。

### 🎨 体验优化

- 工作台正文调整为 11px，页标题 13px，指标数字 13px。
- 工作台表格行从 40px 收紧到 32px，导航和标签降到 28px；同屏可看到更多任务。
- 任务详情、方法编辑器和设置页正文统一为 12px，标题最高 14px。
- 保留宿主原生的会话、模型选择、权限和输入框样式；Saker 只收紧自己的工作区。

### ⚠️ 其他变更

- 结果插件升级到 `1.4.1`；数据、会话、个人方法和知识库保持兼容。
- 对比实验继续暂停；0.7.6 的历史结果仍为双方 64/72、McNemar p=1.0，没有成功率优势。

### ⚠️ 边界

- 未修改 Windows 显示缩放，只调整 Saker 自己的 CSS 字号与行高。
- 不发布、不 push、不提交 Git。
