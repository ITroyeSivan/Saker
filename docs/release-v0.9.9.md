# Saker 0.9.9

### ✨ 新增功能

- 新增 54 个内置测试模块目录，覆盖信息收集、JS 与接口分析、漏洞验证、组件研究、内网评估、证据复测与专项任务。
- 新增 `saker_test_module` 模型工具：list/describe/define/revise/begin/status/finish/cancel。
- 新增模块版本、调用记录、会话偏好与定义归档表，支持不可变版本、CAS 与调用状态。

### 🐛 问题修复

- 模块草稿按任务隔离，跨 root 读取返回 SCOPE_MISMATCH。
- 完成调用必须附真实产物引用；已完成/已取消调用不能再次取消。
- 同一 work 与执行者不能重复准入活动模块调用。

### 🎨 体验优化

- 模块列表支持文本、分类、分页与别名索引；详情按需返回完整 instructions。
- 内置模块声明真实来源与退出判据，不把工具名当已验证能力。

### ⚠️ 其他变更

- 数据库 schema 升到 9，新增模块相关表；旧数据保留。
- 根包升级到 `0.9.9`，结果插件升级到 `1.4.7`。
- 对比实验继续暂停；不发布、不 push、不提交 Git。
