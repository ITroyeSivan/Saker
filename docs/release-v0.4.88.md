### ✨ 新增功能

- 常规、Nday、0Day 各提供三个可展开、复制的示例；复制失败显示手工选择提示。
- 常规测试增加「收集后自动接 Nday」和「常规与 Nday 同时进行」，共用资料、预算与截止时间。
- 子代理上限可选 0、1、2，流程与人数选择立即保存。
- 交互频率可选仅必要时询问、阶段汇报自动继续、阶段完成后确认；支持任务中调整，阶段确认由服务端守卫。

### 🐛 问题修复

- 修复同站子任务从常规继续到 Nday 时，原工具过滤器遗漏 Nday 本地工具的问题；保留原会话、已用操作数与历史报告。
- 首次分派前检查 Nday 工具包已加载，避免把缺少工具的清单固化进子会话；子会话可加载其已获准的本地工具。
- 修复桌面发布包遗漏用户说明资源的问题。
- 精简重复工具说明，恢复描述长度预算检查。

### 🎨 体验优化

- 两方向各自记录完成状态，全部完成才结束；取消、受阻和预算耗尽时停止自动衔接。
- 同站子任务结束后释放，需要续接时复用原任务；禁止嵌套分派，关闭失败仍占名额。

### ⚠️ 其他变更

- Nday 与常规方向共用任务资料；更新保留用户数据。
- 适用于官方 Windows Desktop 0.2.0-rc.2，更新沿用原有用户数据与 MCP 配置。
