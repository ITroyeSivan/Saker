# Saker v0.2.10

本版继续压缩模型每轮都要支付的工具描述成本，同时把详细语义保留在 refs / 插件手册中。

## 核心变化

| 领域 | 调整 |
|---|---|
| 扫描器 | 六节点降级阶梯不再常驻每个工具 schema，简短摘要之外不再重复 hint；本机缺工具时仍由错误结果原样返回。13 个工具减少约 9K 常驻字节。 |
| redteam 成果 | 登记/更新字段长文继续收口到 `shared/refs/finding-fields.md`，工具 schema 只留字段用途和关键约束。 |
| AttackAtlas | 覆盖、阶段、目标、链路的模式词表移出工具描述；enum 与运行时校验保持不变。 |
| 战役记忆 | 工具描述缩成操作入口；kind、TTL、召回与方向语义保留在插件 README 和运行时行为中。 |
| stage-gate / WebShell / trace | 长流程说明改为短句，详细规则继续由 gate 输出、playbook 与错误提示承载。 |
| 预算门禁 | 新增 `scripts/test-tool-budget.mjs`：已迁移插件单条描述上限 480B、单插件合计上限 6KB，超限即 CI 失败。 |
| MCP 稳定性 | 修复 stdio 子进程关闭写入端时的 `EPIPE` 未处理错误：现在转换为通道失败并拒绝当前请求，不再打挂整个 dsh 宿主。 |

## 设计原则

- 工具 schema 只放模型做“是否调用、调哪个、必填什么”所需的信息。
- 详细字段、模式词表、降级策略保留在 refs、README、playbook 或错误返回中，按需读取。
- 用户可自定义的内容继续放技能和知识层，不塞进所有会话都常驻的工具定义。
- 任何迁移都要同时满足：行为单测通过、预算门禁通过、真实请求体积下降。
