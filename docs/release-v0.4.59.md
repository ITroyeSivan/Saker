# Saker v0.4.59

发布日期：2026-09-27

## 变更

- 渗透测试预设提供四种可选工作组合：常规测试、Nday 发现、按项目/行业身份进行 FOFA 候选发现、0day 挖掘；可按需选择，不再默认串行运行整套扫描。
- 新增 campaign FOFA 候选搜索。查询围绕用户给出的机构、域名、备案号或网络范围，组合 ICP、域名/主机、页面标题、证书及组织/地域线索，纳入仅有 IP 的被动候选；搜索结果保留来源与线索，不写入活动资产清单，也不主动连接候选主机。
- Nday 匹配可接收明确的目标身份并调用 FOFA 被动候选搜索；候选范围与受影响指纹匹配分开处理，避免把宽泛搜索结果当成已验证漏洞。
- 修正 FOFA 返回字段与候选展示：请求备案、ASN、组织、地域和证书字段；无主机名时用 `IP:端口` 展示，并保留机构线索。
- 精简各模式说明，缺少目标身份时不再通过对话追问；文档补充模式用法、FOFA 查询策略与 Nday 信息源。
