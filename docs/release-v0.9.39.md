# Saker 0.9.39

### ✨ 新增功能

- 发现详情和测试路径都能打开精确版本的请求原件；无回执的历史版本也可按归档记录读取，返回保留原列表位置。
- 复核历史支持继续读取：最近 10 条之后可加载更早记录，第 11 条起在 Desktop 可达；切换任务会丢弃旧响应。

### 🐛 问题修复

- 请求到回执的关联键加入所有者：根会话与已登记子会话存在同名同版请求时，不再把子会话回执挂到根请求；跨会话必须使用已保存的精确执行引用。
- 测试路径为请求引用建立版本化节点，并只把该请求自己的回执连到节点；历史与失效状态在节点和边上保留。
- 材料依据统一检查“普通文件、可读、登记摘要”：目录、不可读文件、摘要不符不能作为“依据足以支持”；没有登记摘要的旧资料标为未核。
- 复核依据摘要加入服务端核过的内容指纹、所有者和版本；原文件变化或不可核时，已保存判断保留为历史并标当前依据失效。
- 报告预览的显示仍限量，但快照覆盖全量引用；第 501 条以后的状态变化也会让旧预览拒绝下载，未变化时可正常下载。
- 修复复核历史加载使用详情字段而不是发现 ID 的问题；“加载更早”现在能取到第 11 条之后。

### 🎨 体验优化

- 请求详情显示端点、账号、版本、历史标记、内容指纹和关联检查，原文分段只读且遮蔽密钥。
- 材料复核选择会显示可核状态；“依据足以支持”只接受当前可核的原件。
