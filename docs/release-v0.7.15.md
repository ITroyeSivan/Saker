# Saker 0.7.15

本版把组件事实、公告/安全更新和最近评估放进官方 Desktop 的“任务详情”，不需要再在聊天里问模型。

### ✨ 新增功能

- 任务详情按需读取当前会话的组件事实、公告/安全更新和评估记录。
- 显示组件数量、公告/更新数量、评估数量；展开可看产品/版本/目标映射、修复版本和最近判定。
- 组件摘要只在打开任务详情时读取，不新增模型调用或常驻轮询。

### 🐛 问题修复

- 组件记录不再是只存在于聊天的不可见账本。
- 组件读取失败时在任务详情内显示可恢复错误，不影响原任务详情。

### 🎨 体验优化

- 组件摘要默认折叠，避免挤占对话区。
- 列表限制条数和最大高度，保持任务详情可滚动。

### ⚠️ 其他变更

- 组件事实仍不等于漏洞；目标行为、影响和独立复核继续分开记录。
- 不发布、不 push、不提交 Git。
