# Saker 0.7.20

本版修正 MCP 代理调用的参数传递：模型把参数作为 JSON 字符串传入时，代理会先解析成对象再转发，而不是把字符串原样送到 MCP server。

### ✨ 新增功能

- `mcp_call` 同时接受参数对象和 JSON 字符串。
- 解析失败或传入数组时返回明确错误，不再把错误参数转发给 server。

### 🐛 问题修复

- 修复 Yakit 的 `ostype` 等无参数工具收到 `"{}"` 字符串后返回 `Invalid tool parameters` 的问题。
- 空参数、普通对象、JSON 字符串保持同一调用语义。

### 🎨 体验优化

- 代理调用仍只暴露 `mcp_search` / `mcp_call`，不把 154 个 Yakit 工具全部塞进每轮上下文。
- 连接状态、工具目录和调用结果继续按需读取。

### ⚠️ 其他变更

- MCP 工具仍受任务范围与“允许访问网站”限制；本地工具也不绕过授权。
- 不发布、不 push、不提交 Git。
