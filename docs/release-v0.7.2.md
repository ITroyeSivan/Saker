# Saker 0.7.2

本版重做首次使用路径和主要面板文案，让第一次打开 Saker 的用户先知道“从哪里开始、点一下会发生什么”，再决定是否进入高级设置。原有会话、账号、个人模板、任务历史、MCP 配置和日常数据保持不变。

### ✨ 新增功能

- 新会话首屏提供“测一个网站 / 审查一段代码 / 解一道比赛题”三张场景卡；点击只填入可编辑示例，不发送、不调用模型。
- 场景卡连续点击会替换上一段示例；用户自己写过的内容会保留并在末尾追加新示例。
- 输入框工具条统一为「多助手 / 附件 / 说法 / 设置」，不再用“协作关”“添加资料”等状态词。
- 设置改为「范围 / 资料 / 节奏」三页：分别回答测哪里、能不能查本地资料、时间与用量怎么限制。
- 附件面板支持文件、文件夹和粘贴；没有选择内容时明确禁用“添加到当前任务”。
- 常用说法面板支持选模板、填空白、直接改正文、复制或插入输入框；插入不会自动发送。
- 执行记录统一为「时间 / 做了什么 / 对象 / 状态 / 账号 / 用时 / 依据」七列，并把顶部统计写成“工具 N 次 · 模型 N 次”。

### 🐛 问题修复

- 修复连续点不同场景卡时，多段示例不断累积、输入框越来越长的问题。
- 修复宿主返回无名内部 preset 时，场景菜单出现空“其他模式”条目的问题。
- 修复会话装载中的 HTTP 400 原样显示为报错的问题；现在显示“会话还在准备中”并提供重试。
- 修复执行记录仍使用“工具调用 / 模型调用”等旧文案导致的界面与说明不一致。

### 🎨 体验优化

- 范围页只保留授权目标、访问限制和只读选项；限速、排除路径和测试重点收进“高级”。
- 多助手默认关闭，开启后才显示并行数量和可选模型；默认说明“一个助手按顺序完成”。
- 常用说法、附件和设置抽屉统一圆角、间距、行高和明暗主题回退，窄窗口仍可滚动操作。
- 场景菜单只显示有名称、可实际选择的模式，不再把内部空预设暴露给用户。

### ⚠️ 其他变更

- 需要 Node.js 24.9 或更高版本；当前适配官方 Desktop 0.2.2-rc.1。
- 本版未执行真实付费模型的裸 dsh 与 Saker A/B 对比，因此不宣称效果领先；现有本地知识检索指标只说明检索行为。
- 更新会先备份配置与关键数据，并刷新 `Saker (dsh Desktop)` 快捷方式。
- 本版未发布到 GitHub Releases，也未提交 Git。
