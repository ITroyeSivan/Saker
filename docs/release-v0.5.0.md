# Saker 0.5.0

0.5.0 重新收拢了产品边界：安全测试从用户给出的目标、文件或问题直接开始，不再依赖公共知识库、Nday 资料库或固定方法编排。

## 主要变化

- 新增清楚的“自由测试 / 按文档测试”场景选择。常规、Nday、0Day 保留为自由测试中的方向偏好。
- 移除知识库、Nday 情报采集、资料整理和后台更新链。新版本不再安装或激活 `dsh-knowledge-hub`、`dsh-nday-hunter`。
- CVE、公告、仓库和 EXP 继续按需直接读取；目标工具、扫描器和资产平台仍可正常使用。
- `oob_probe` 迁入扫描工具，支持新建带外标识、批量归因、平台回查、取消和配置缺失错误。
- 安全配置的工具库新增 Chrome for Testing 路径，可直接填写独立浏览器目录，并用于自由测试和按文档测试。
- 删除固定 17 项测试内容、旧模块门禁、自动常规转 Nday 和依赖任务工具链作为新任务前置。
- 任务进度重新显示当前入口、身份、可测请求、下一步与缺项，不再只显示抽象计数。
- 工具面按资产发现、主动扫描和依赖任务分组加载；核心任务、上下文、执行、证据和成果工具保持可见。
- 清理旧知识 UI、旧情报设置页、失效导入和退役回归，保留项目文档、浏览器、请求对照、恢复与交付能力。
- 修复 `project_check next/detail` 的可选字段输出，真实宿主不再因 `undefined` 拒绝无损 JSON。

## 升级说明

- 使用 0.5.0 安装器升级；官方插件管理会移除两份退役插件，用户会话、项目文档、历史数据库、模板和 MCP 配置保留。
- 旧归档仍可读取；`saker.task-archive/2` 会在完整校验后忽略已退役知识区，新归档使用 `saker.task-archive/3`。
- 以前自行保存的资料目录不会被删除、扫描或自动导入。用户可以像普通文件一样把需要的目录交给当前任务读取。

## 安装

当前版本要求 Windows 官方 DeepSeek Harness Desktop 0.2.1-rc.2，兼容 0.2.0-rc.2。安装步骤见 [安装说明](getting-started.md)。

## 边界

本版不提供漏洞检出率、SRC 成绩或成本领先承诺。模型和工具结果仍需结合授权范围、身份、业务对象和原始证据复核。Saker 面向个人学习和获授权测试，暂不建议直接用于生产环境。
