Saker 0.5.0 重新收拢了测试入口和产品边界。新会话可以明确选择自由测试或按文档测试；常规、Nday 和 0Day 保留为自由测试中的方向偏好。公共知识库、Nday 资料库和固定方法编排不再属于产品运行路径。

### ✨ 新增功能

- 新增清楚的“自由测试 / 按文档测试”场景选择，切换场景不会伪造项目任务或固定检查编号。
- 自由测试可直接使用受管 Chrome for Testing 打开、观察和操作页面，并保存页面观察材料。
- 安全配置的工具库新增 Chrome for Testing 路径，可填写独立浏览器目录。
- 带外验证迁入扫描工具，支持新建回连标识、批量归因、平台回查、取消和明确的配置缺失提示。
- 任务进度显示当前入口、实际身份、可测请求、下一步和缺项，不再只显示抽象计数。

### 🐛 问题修复

- 修复项目检查详情和下一项输出含 `undefined`、被官方宿主拒绝为无损 JSON 的问题。
- 修复自定义 Chrome for Testing 路径在工具映射和条目同时存在时可能解析到错误路径的问题。
- 修复工具退役后客户端仍保留知识入口、情报设置和旧 RPC 调用的问题。
- 修复旧归档包含知识区时的恢复兼容：新归档使用 `saker.task-archive/3`，旧 v2 完整校验后忽略退役区。
- 修复项目任务恢复时浏览器会话和未知写入核对状态可能失真的问题。

### 🎨 体验优化

- 聊天输入区只保留提示词模板、添加测试资料和测试设置三个入口。
- 删除固定 17 项测试内容、旧流程控件和知识/Nday 工具包，减少无关界面与模型工具声明。
- 新归档检查表、来源、发现、截图和附件仍可在离线交付中查看。
- README 重写为真实界面、场景入口、浏览器验证和安装说明，并补充 0.5.0 产品变化。

### ⚠️ 其他变更

- 版本更新到 0.5.0；不再打包或安装知识库和 Nday 资料库插件。
- 适用于官方 Windows Desktop 0.2.1-rc.2，同时兼容 0.2.0-rc.2。
- 旧会话、项目材料、模板、MCP 和账号配置保留；升级会由官方插件管理移除退役插件。
- CVE、公告、仓库和 EXP 由任务按需直接读取；用户自行保存的资料不会被自动删除或扫描。
- Saker 面向个人学习和获授权测试，暂不建议直接用于生产环境。
