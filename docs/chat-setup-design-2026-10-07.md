# 聊天中的任务设置

用户需要在写任务时决定希望怎样推进，开始后也应能调整。交互频率、子代理人数和提示词准备放在聊天输入框上方；默认只在必要时询问，运行中的任务仍保持原范围、额度和截止时间。

## 入口与层次

| 常见动作 | 现在的位置与行为 |
|---|---|
| 选择任务方向 | 输入框上方，常规测试、Nday、0Day；默认常规。开始后固定当前方向，实际阶段转换会更新显示 |
| 决定何时回复 | 同一行的交互菜单：仅必要时询问、阶段汇报自动继续、阶段完成后等我确认 |
| 控制子代理 | 同一行选择不使用、最多1个、最多2个。按需分派，共用预算；增加人数可能增加模型用量 |
| 写或复制任务提示词 | 点击「写提示词」展开编辑区。选示例、快捷填空或直接修改全文，然后插入输入框或复制 |
| 选择常规与Nday的安排 | 「更多设置」中选择只做当前方向、先常规后Nday、一起推进 |
| 保存个人习惯 | 「更多设置」中把交互频率和人数设为新会话默认；已有明确设置和运行中的任务保持原配置 |
| 阶段之间继续 | 聊天中显示阶段摘要、「确认并继续」和「停止本轮」；不要求去成果页找按钮 |
| 结束后再问一个问题 | 在聊天中点击「保留资料，设置下一轮」，沿用当前交互和人数，再选择方向并写新问题；不会自动开始模型或重置运行中的任务 |
| 查看详细资料、预算及成果 | 保留在「redteam 成果」，避免常用聊天入口堆满记录和统计 |

设置栏在空白会话和已有聊天中持续存在。默认值在新会话打开时保存为实际偏好，保存本身不启动任务、模型或工具。渗透测试专业入口使用这套设置；其他宿主模式保留其原入口。

## 提示词的使用顺序

1. 选择方向，打开「写提示词」。每个方向提供三个起点，也可从空白开始。
2. 填入目标、范围、身份等占位信息；全文会随填写更新。
3. 需要自由表达时直接改全文，快捷填空收起，避免后续填空覆盖手写内容。
4. 选择「插入到输入框」或「复制提示词」。插入使用宿主输入框的当前光标位置和版本检查，保留原草稿、文件引用和附件；不会自动发送。输入框在变化时拒绝插入并保留编辑内容。
5. 检查输入框，再自行发送。复制失败时，全文仍可选中手工复制。

草稿按会话和方向自动保存，刷新后恢复；关闭编辑区也保留内容。选择另一个模板会替换编辑区内容，不改聊天输入框。常用提示词可保存为本机个人模板，在其他会话选用；同方向、同名称更新原模板，最多30个。未发送的草稿和模板不会自动加入模型上下文。

编辑区就地展开，限制高度并允许内部滚动；聊天输入框持续可见。控件有名称、保存和失败提示，按 Escape 关闭后焦点返回「写提示词」。窄窗口中设置行换行。

## 运行中的调整

改变交互频率会影响后续推进，原操作额度与截止时间保持。已经等待确认的阶段仍需一次显式确认；调成自动继续不会自行解除等待。缺关键资料、需要登录、访问受阻及预算耗尽时，任何频率都暂停说明。

运行中也能改子代理上限。名额包含运行、空闲、关闭中及关闭失败的子代理，不能通过降低数字抹掉占用；需要先在任务详情关闭，再降低上限。主任务与子任务共用本轮额度，子任务不能再派子任务。
