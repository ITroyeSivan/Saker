# Saker 0.7.5

> 历史版本。0.7.6 已补齐 J01/J02 迁移身份与语义判等，当前说明见 `release-v0.7.6.md`。

本版处理 0.7.4 独立复核发现的 H01–H04，重点是旧知识升级迁移的安全性和幂等性。

### ✨ 新增功能

- 知识迁移遇到相同 `sourceId`、不同正文时，会保留旧版本并记录冲突来源，不再用一个版本覆盖另一个版本。

### 🐛 问题修复

- 迁移旧知识时会按目标工作区重新计算文档身份，并同步迁移章节、检索索引和正文文件。
- 相同 sourceId、不同正文或必要元数据不再被静默删除；旧条目会以带冲突标记的兼容 sourceId 保留，新旧正文都可检索。
- 只有内容与必要元数据都一致的重复条目才会合并。
- 旧比赛资料的迁移状态改为按“根会话 + 目标工作区 + 源修订”分别记录，同工作区多个旧会话不会再互相跳过。
- 源比赛资料修订变化后，会重新导入并更新索引。
- 迁移后的条目可正常重复导入和更新，不再触发 `knowledge_documents` 唯一键错误。
- 关闭知识时，聊天组件的模型/去向预取不再打开、创建或迁移知识索引。

### 🎨 体验优化

- 升级迁移保持原有标题、来源和正文可读；同 ID 不同内容的旧版本以可见的兼容来源保留。
- 模型/去向预取只读取元数据，不再因为打开聊天输入区而产生额外知识索引 IO。

### ✅ 验证

- 新增 H01–H04 行为回归，覆盖同 ID 冲突、同工作区多根会话、迁移后重复导入和关闭知识时零索引访问。
- 保留 G01–G06 与 F01–F11 回归，旧库只读检查仍为 12,847 篇 / 160,905 片段。

### ⚠️ 其他变更

- 本版未执行真实付费模型 A/B，不宣称模型效果领先。
- 外部 Burp/Yakit MCP 通话、真实模型 tool schema 和 125%/150% 缩放仍未作为本版通过项。
- 本版未发布，也未提交 Git。
