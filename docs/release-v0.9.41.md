# Saker v0.9.41

本版汇总自 v0.6.3 以来的桌面工作流改进。在 dsh 会话中导入材料和说明问题，从 Saker 工作台定位任务、查看原件与覆盖情况，完成人工复核后预览并导出报告。

### ✨ 新增功能

- 新增独立 Saker 工作台入口，集中查看任务、发现与证据、待办、配置与资料和执行日志。任务内可在概览、执行记录、测试路径、发现、资产与文件之间切换。
- 增加可搜索的测试路径和资产覆盖视图。发现可以沿保存的引用打开对应请求或执行记录。覆盖视图分别显示已测、未测和受阻情况。
- 发现详情增加人工依据复核。可记录依据不足、保存新的判断或更正旧判断，保留可回看的复核历史。隔天打开任务时可从摘要直接查看待复核记录。
- 执行记录增加按轮次对账的模型用量视图。可查看已观察到的传输、已结算 tokens、缓存和未知用量，区分任务额度与统计结果。
- 完善项目资料和个人知识管理。项目导入保留要求来源及位置，分段查看原件。整理知识先生成或编辑为草稿，用户检查来源和适用条件后保存。

### 🐛 问题修复

- 精确引用按所属任务、所有者和版本打开。不同会话的同名记录不会被互相借用，旧引用存在多个版本时提示补明依据。
- 长原文分段查看时保持 UTF-8 字符边界，跨页的常见认证头继续遮蔽。材料缺失、不可读取或摘要不符会影响当前复核可用性，旧判断仍可查看。
- 预览与下载使用同一份报告快照。引用或复核状态变化后，旧预览会提示刷新。页面发生渲染异常时保留导航、重试和返回入口。
- 安装包引用改为 profile 对应的持久目录，清理解压副本后仍可维护。回退前检查所需版本的包文件与可验证摘要。

### 🎨 体验优化

- 空白会话直接显示原生输入框和一条快捷栏，移除首屏提示和三张场景卡。测试流程、测试模块、指令模板与附件入口继续可用。
- 重整发现、材料和执行详情的分栏与返回路径。长列表可搜索、筛选和翻页，返回时保留所在任务与列表位置。
- 指令模板支持直接编辑、另存和插入输入框。范围、知识与运行限制集中到设置面板。更新首页和功能截图，以桌面界面及演示资料说明工作流。

### ⚠️ 其他变更

- 本版面向 Windows 官方 DeepSeek Harness Desktop 0.2.2-rc.1。安装维护脚本需要 Node.js 24.9 或更高版本。
- 用户资料继续使用已有 dsh profile。安装包含 10 个功能插件和 1 个根包，更新后沿用持久包目录及 Windows 桌面快捷方式。
- 项目继续面向个人学习和明确授权的安全审查。
