# Saker 0.9.2

本版修复 Desktop 重启后的角色恢复：不再把已经丢失的 Host 子代理显示为仍在运行，也不会自动重放未知结果。

### ✨ 新增功能

- 启动后对账持久化角色、工作、尝试和 worker 记录与实际 Host 子代理状态。

### 🐛 问题修复

- 修复 Desktop 重启后 active 角色和 worker 一直显示运行、排队项不明确的问题。
- 缺少运行中子代理时，角色收口为结果未知、worker 收口为释放未确认，不再伪装成功。
- root 在存在未决子任务时进入等待用户，不自动继续旧业务。

### 🎨 体验优化

- 排队中的角色保持排队，只有用户明确恢复时才启动，不会在重启后抢占名额。
- 工作台继续显示真实状态：结果未知、释放未确认和排队分别可辨。

### ⚠️ 其他变更

- 结果插件升级到 `1.4.2`；工作、角色、消息、回执和旧会话数据保持兼容。
- 对比实验继续暂停；0.7.6 的历史结果仍为双方 64/72、McNemar p=1.0，没有成功率优势。

### ⚠️ 边界

- 重启不一定能恢复原 Host 子代理；本版明确记录未知，而不是声称恢复成功。
- 不发布、不 push、不提交 Git。
