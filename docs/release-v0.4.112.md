本页汇总 0.4.110–0.4.112 的集中改进，方便从 0.4.109 或更早版本升级的用户了解变化。主要调整是把“按文档测试”接入聊天入口，并完善项目记录、运行控制和结果展示。0.4.112 的运行插件与 0.4.111 相同，新增调整集中在首页说明和截图。

### ✨ 新增功能

- 聊天顶部新增“按文档测试”。添加本地 Word、Excel 或文本后，模型可读取原文位置、整理检查项并逐项执行。
- 文档保留来源和修订；相同内容重复导入可复用已有修订，目录支持分页读取。
- 项目 HTTP 请求向模型返回有限响应正文、相关响应头和回执引用，便于结合实际结果继续分析。

### 🐛 问题修复

- 修复项目检查结束后任务栏仍显示进行中的情况，并区分结束、等待条件和暂停。
- 修复请求排队期间取消仍留下已派发记录的问题，取消等待不提前扣除派发额度。
- 补齐项目浏览器动作与检查项的关联，暂停或停止时关闭受管浏览器。
- 任务归档新增项目运行、来源、检查和动作四类记录。
- 修复部分 Windows 环境使用 SOCKS `ALL_PROXY` 时无法启动 Desktop 的问题，保留 HTTP/HTTPS 代理设置。

### 🎨 体验优化

- 项目设置隐藏实战专用的测试内容、子代理和模型分配控件。
- 首页更新项目结果截图，保留资料、设置、执行记录和工具配置等功能介绍。
- Chrome for Testing 路径可由桌面启动配置保存，减少重复配置。

### ⚠️ 其他变更

- 适用于官方 Windows Desktop 0.2.1-rc.2，同时兼容 0.2.0-rc.2；更新沿用原用户数据、会话和 MCP 配置。
- 项目正在快速迭代，目前仅供个人学习与授权实验，暂不建议用于生产环境或正式项目交付。
- 0.4.110、0.4.111 的历史标签和安装附件保留；本页提供集中更新说明。
