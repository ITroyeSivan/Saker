# Saker 0.7.21

本版修正“每一步都问”的确认方式：不再让模型调用已隐藏的 checkpoint 工具，而是使用宿主原生的提问面板。

### ✨ 新增功能

- “每个检查步骤前问我”和“改动网站数据前问我”都会要求模型用 `ask_user_question` 提供“继续 / 停止”按钮。
- 用户选择前模型停下，不自行进入下一步或修改数据。

### 🐛 问题修复

- 修复确认提示仍引用已隐藏的 `redteam_task`/`saker_task` checkpoint，导致模型只能在正文里列 A/B/C 的问题。
- 新增回归：确认提示必须包含 `ask_user_question`，且不得出现已隐藏的工具名。

### 🎨 体验优化

- 确认项使用原生按钮，窄窗和键盘操作沿用宿主行为。
- 停止本轮后状态入口显示“新建测试”，不会继续发模型请求。

### ⚠️ 其他变更

- 确认偏好不改变任务范围、预算或审批规则。
- 不发布、不 push、不提交 Git。
