# Saker 0.7.16

本版保留 0.7.15 的组件事实/公告/适用性能力，并修正紧凑会话栏在长方法名、长状态文本下的宽度约束。

### ✨ 新增功能

- 任务详情按需读取当前会话的组件事实、公告/安全更新和评估记录。
- 显示组件数量、公告/更新数量、评估数量；展开可看产品/版本/目标映射、修复版本和最近判定。
- 组件摘要只在打开任务详情时读取，不新增模型调用或常驻轮询。

### 🐛 问题修复

- 方法名和状态入口的宽度上限不再被通用按钮样式覆盖；长方法名会省略而不挤占相邻入口。
- 状态文字改为独立可省略节点，长状态在 125%/150% 缩放下也不横向溢出。
- 已取消、暂停接续或超过截止时间的轮次会在状态入口直接标出“新建测试”，并在悬停说明后续消息不会发出，避免继续输入后只看到运行时错误。
- 没有任务策略的未开始会话不再因为内部 `preparing` 占位状态每 3 秒轮询；空会话关闭面板后保持零后台读取。
- 组件记录读取失败时在任务详情内显示可恢复错误，不影响原任务详情。

### 🎨 体验优化

- 常驻栏保持单行 40 CSS px；1279×820、800×600 与真实 125%/150% 缩放下均无横向溢出。
- 组件摘要默认折叠，避免挤占对话区；列表限制条数和最大高度。

### ⚠️ 其他变更

- 组件事实仍不等于漏洞；目标行为、影响和独立复核继续分开记录。
- 不发布、不 push、不提交 Git。
