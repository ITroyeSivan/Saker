# Saker 0.9.35

### ✨ 新增功能

- 发布包增加 `build-info.json` 与 `LATEST.json`，用同一个 `buildId` 标识 ZIP、包清单和日常安装记录。
- 发布入口增加 ZIP 的独立 `.sha256` 文件，便于下载后直接核对。

### 🐛 问题修复

- 原文分页读取改为按原始字节范围定位敏感头行；`Authorization`、`Cookie` 等值即使跨过页边界，也不会在下一页露出后半段。本地详情与模型续读使用同一遮蔽语义。
- Saker 工作台把整页内容构建移入错误边界内部。执行表或其它页面在构建阶段抛错时，外层导航仍保留，并显示“当前页加载失败 / 重试 / 返回测试任务”，不会白屏或重放页面动作。

### 🎨 体验优化

- 全局导航和功能名改为安全工具常用术语：概览、测试任务、发现与证据、HTTP 记录、资产与文件、待办事项、配置与资料、执行日志。
- 任务页签统一为概览、执行记录、测试路径、发现、资产与文件；执行类型与状态显示为“模型回合 / 已结算”等中文。
- 发现严重度显示中文；资产表显示“资产 / 请求 / 文件 / 检查项”和可读任务名，不再直接露出 `request` 或裸会话 ID。
- 会话快捷条统一为测试流程、测试模块、指令模板、附件；并行任务面板不再混用“助手 / 协作”。

### ⚠️ 其他变更

- 根包升到 `0.9.35`。
- `@dsh-external/dsh-redteam-results` 升到 `1.4.28`。
- 对外 ZIP、`packages.json`、`build-info.json`、`SHA256SUMS.txt` 和日常安装记录使用同一版本与哈希。
- 未发布、未 push、未提交 Git。
