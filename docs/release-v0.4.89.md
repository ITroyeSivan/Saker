# Saker 0.4.89

聊天输入框上方现在持续提供任务方向、交互频率和子代理人数。开始聊天后入口仍在，阶段等待时也能直接确认继续。

提示词支持选示例、快捷填空、自由编辑、插入输入框和复制。草稿自动保存，个人模板可跨会话复用；准备和复制不会自动发送。交互频率和子代理人数可保存为新会话默认，运行中调整保留原操作额度与截止时间。

使用方式与实际截图：[聊天设置设计](https://github.com/ITroyeSivan/Saker/blob/v0.4.89/docs/chat-setup-design-2026-10-07.md)。完整记录：[Desktop 验收](https://github.com/ITroyeSivan/Saker/blob/v0.4.89/docs/verification/chat-setup-2026-10-07.md)。下载桌面 ZIP 后运行其中的安装器，桌面快捷方式继续使用日常配置与数据。
