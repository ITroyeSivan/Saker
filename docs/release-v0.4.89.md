### ✨ 新增功能

- 聊天输入框上方持续提供方向、交互频率、子代理人数和「写提示词」入口。
- 提示词可选示例、快捷填空、自由编辑、插入和复制；草稿自动保存，个人模板可跨会话复用。
- 交互频率和人数可保存为新会话默认，阶段等待时可直接在聊天中确认继续。

### 🐛 问题修复

- 设置被拒绝时保留错误提示和原人数，避免定时刷新掩盖失败。
- 草稿按会话与方向隔离，延迟的旧保存不能覆盖新编辑。

### 🎨 体验优化

- 已有聊天保留快捷设置；插入提示词保留原输入内容，准备与复制不会自动发送。
- 运行中调整交互或人数保留原预算、截止时间和阶段等待；结束后可保留资料选择下一轮。

### ⚠️ 其他变更

- 聊天设置应用于当前任务；更新保留已有配置。
- 适用于官方 Windows Desktop 0.2.0-rc.2，更新沿用原有用户数据与 MCP 配置。
