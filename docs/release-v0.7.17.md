# Saker 0.7.17

本版把“正在验证的具体问题”放到测试结果页主视图，用户不再只能看执行流水和步骤进度。

### ✨ 新增功能

- 结果页新增“正在验证”分类，默认展示当前会话的具体问题、状态、绑定请求/身份、尝试次数和下一步需要的信息。
- 每条问题可展开正常行为、支持判据、反证条件、边界、处理路径和观察记录。
- 没有具体问题时显示明确空态，并可直接切到“运行记录”。
- 研究与问题数据只在打开该页时读取，不新增常驻轮询或模型调用。

### 🐛 问题修复

- 研究假设数据此前只有底层记录，没有面向用户的主视图入口。
- 结果页默认不再只显示执行流水；问题、运行、发现、资料保持单一分类栏。

### 🎨 体验优化

- 问题列表只复制标题、入口、身份和计数，不把原始响应正文带进索引。
- 观察记录默认折叠；长文本、长入口和长身份可换行，不撑破窄窗。

### ⚠️ 其他变更

- 问题状态描述“工作”，不等于漏洞结论；未确认前不会写成已证实。
- 不发布、不 push、不提交 Git。
