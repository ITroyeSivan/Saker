# Saker 0.7.3

本版修复独立审查发现的会话隔离、知识恢复、预算账本和资料读取问题。0.7.2 的首次使用路径与主要面板保持不变。

### ✨ 新增功能

- 旧版 634MB 参考手册库恢复为只读检索来源，并可按旧资料路径分页读取；不改写或迁移原库。
- 同一工作目录下的多个会话共享项目资料；整理稿可明确保存为当前项目或“所有会话可用”的个人全局资料。
- 文件型本地检索改由可终止 worker 执行，取消不再等待同步 SQLite 扫描。
- 整理确认页在发送前显示实际模型、本地/云端去向和待发送字节数。

### 🐛 问题修复

- 修复合法 ref 被其他会话读取、整理 requestId 跨会话读写、旧草稿覆盖新编辑的问题。
- 修复“只查本地资料”仍可读取网页 ref 的问题；网页 ref 现在绑定项目、策略和签名。
- 修复资料列表按 sourceId 打不开的问题，并支持跨章节继续读。
- 修复启动参数可抬高用户已保存的未计量通道上限。
- 修复比赛设置看不到真实模型已用/预留、允许把上限降到已用以下、允许保存过期时间的问题。
- 修复手工整理没有发出模型请求却被计入模型调用和未知费用的问题。
- 修复长查询返回超过 3072B、或删空结果却仍标记命中的问题。
- 修复外部适配器不响应取消时仍要等满超时的问题。

### 🎨 体验优化

- 整理流程拆成“预览去向 → 开始生成/手动编辑”，不再点击按钮后立即发送。
- 资料读取按章节和 8192B 分段，继续读不会回到第一页。
- 比赛、案例中的旧资料工具不再进入新模型工具清单，统一使用当前资料入口。

### ⚠️ 其他变更

- 需要 Node.js 24.9 或更高版本；当前适配官方 Desktop 0.2.2-rc.1。
- 本版未执行真实付费模型的裸 dsh 与 Saker A/B 对比，因此不宣称效果领先。
- 本版未发布到 GitHub Releases，也未提交 Git。
