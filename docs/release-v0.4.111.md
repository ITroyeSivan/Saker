> 0.4.110–0.4.112 的集中更新说明见 [最新发布页](https://github.com/ITroyeSivan/Saker/releases/tag/v0.4.112)。本版本标签和安装附件保留。

### ✨ 新增功能

- 项目同名文档更新现在建立连续修订号，重复导入相同内容会复用已有修订；每次运行只固定各来源的最新修订。
- 文档目录支持游标分页，大文档不会因为只显示前 200 个段落而无法继续读取。

### 🐛 问题修复

- 修复 HTTP 请求等待速率或并发名额时取消仍留下 dispatched 动作的问题；queued 取消不会到达目标，也不会提前扣除派发额度。
- 修复项目浏览器目标动作没有项目动作记录、暂停后仍可继续操作的问题；浏览器目标动作现在共用额度、控制版本、检查关联和停止关闭。
- 修复模型提前调用 `planComplete` 让项目运行卡在 running 的问题；项目完成只能由来源整理和检查状态判定，提前完成会转为等待并暴露实际缺口。
- 修复项目任务归档遗漏运行、来源、检查和动作四类记录的问题；恢复后会重写新任务归属，账号秘密仍需重新绑定。
- 项目检查现在可以显式关联本会话 finding 引用，错误引用会被拒绝。

### 🎨 体验优化

- 按文档测试的测试设置隐藏测试内容选择、子代理和模型分配等实战专用控件，保留目标、限制、账号和项目启动所需入口。
- 浏览器观察、请求列表和关闭属于本地读取，不额外消耗目标动作额度。
- 桌面启动配置现在可以持久保存 Chrome for Testing 路径；安全配置里的浏览器工具路径和启动环境会共同生效。

### ⚠️ 其他变更

- 版本更新到 0.4.111；`dsh-redteam-results` 升级到 1.0.182。
- 适用于官方 Windows Desktop 0.2.1-rc.2，同时兼容 0.2.0-rc.2；更新沿用原用户数据、会话和 MCP 配置。
