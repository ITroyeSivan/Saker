### ✨ 新增功能

- 按文档测试的进度、当前检查、发现问题、历史运行和导出入口现在直接显示在对话上方；完整检查表可从“查看检查表”展开。
- 项目历史运行可单独查看；项目来源、检查表、动作、回执和问题材料可以按所选运行快照导出离线文件。
- 浏览器动作支持独立身份 profile、显式关联 API、真实上传下载、弹窗处理和稳定请求分页；正文不可得与空正文分别显示。
- 项目检查定义支持幂等批次、依赖检查、循环检测和依赖事实校验，同一内容重试不会重复创建检查项。

### 🐛 问题修复

- 完整“未发现问题”必须有本次有效动作或明确复用观察；完整“发现问题”必须引用已复核 finding。暂停后的底层迟到结论不能再写入本轮。
- 排队动作在恢复、范围变化、身份变化或策略变化后失效，不请求目标，也不扣除派发额度。
- 受管 Chrome for Testing 在请求发出前检查目标范围，覆盖导航、重定向、iframe、XHR 和新窗口；非法请求不会到达目标。
- HTTP 响应断线、超时、取消和提前关闭统一收尾并释放并发槽；未知写入保留副作用状态，支持人工核对后继续。
- 请求、回执、浏览器详情、诊断和导出统一遮蔽常见密码、Token、Cookie、Set-Cookie、URL 密钥和私钥字段。
- 任务归档严格校验 manifest、分节摘要、行数、允许表和列；恢复时暂停未完成运行、取消 queued、标记未知 dispatched，并保留附件引用。
- 文档解析限制 ZIP 与解压输出大小、条目数量和单次读取长度；XML 属性读取不再依赖书写顺序，筛选和图形对象会显示未解析提示。

### 🎨 体验优化

- 聊天内检查表使用稳定列宽，结果列不再被挤成逐字换行；窄窗口保留横向滚动。
- 设置区只保留项目目标、范围和限制，不再复制完整检查表；查看与刷新不产生模型调用或目标请求。
- 模型调用改为分开显示会话事件、准入记账、辅助调用、未知用量和缓存读取，避免用单一口径替代全部调用。
- README 重新整理为真实工作流、界面截图、执行证据和安装入口，减少抽象描述。
