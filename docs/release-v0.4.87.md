### ✨ 新增功能

- 渗透测试统一为常规测试、Nday 发现、0Day 挖掘三个方向，按具体问题组织任务、预算和材料。
- 漏洞情报支持选源更新、逐源进度和失败重试；Nday 按产品与版本核对适用条件。
- 增加页面、JS、请求与业务材料整理，支持对照验证、独立复核和报告材料包导出。
- 增加 Windows 桌面安装器，安装后自动创建或刷新 Saker 快捷方式。

### 🐛 问题修复

- 修复 MCP 直接接入的环境变量与请求头兼容问题，以及服务器列表不刷新的问题。
- 修复 MCP 代理调用漏记、错误调用被记为成功和挂载错误状态丢失。
- 修复同版本插件更新可能复用旧缓存的问题，安装后检查文件内容。

### 🎨 体验优化

- 相关线索持续验证，缺资料、方向调整或访问受阻时再与用户确认；IP 被封后停止请求。
- 子任务按需分派，同站复用、最多两个，结束后回收；资料和工具按需读取与加载。
- 重写 README、安装说明和历史发布说明，更新首页功能图。

### ⚠️ 其他变更

- 移除 SRC 范围策略，以及代码审计、CTF 的新任务入口；历史会话仍可读取。
- 本版已在 Windows 官方 Desktop 0.2.0-rc.2 验证。其他宿主版本尚未验证。
- 受控测试不代表真实站点检出率，也不保证所有任务节省 token；Nday 对照中用量增加。
