# Saker 0.8.0

本版按实战重构方案完成 P0–P2 的核心工程改动：修正组件身份和版本语义，新增有界的公开上游研究，并把协作从固定复核/报告扩展为模型可定义的动态角色和具体工作。

### ✨ 新增功能

- 组件身份保留 Unicode，中文产品不再被清洗成空串；产品别名必须显式提供。
- 版本范围保留开闭上下界，支持正式版与标准预发布顺序；无法识别的发行商后缀返回 `unknown`。
- `saker_component` 新增公开上游映射和有限版本窗口研究，不需要用户先提供仓库或修复 commit。
- 新增 `saker_role`：RoleSpec、WorkItem、RoleInstance、Attempt 和持久消息。
- 模型可以创建非预设角色；负责人可以提出子工作，root 统一准入、计量、停止和恢复。
- 方法编辑支持同名工具的批量替换。

### 🎨 体验优化

- 新任务默认 15 分钟、最多 2 个活动子实例、24 次模型调用和 60 次工具调用；用户明确留空仍可取消插件附加上限。
- 任务详情按需显示具体问题、角色分工、通信交接和失败状态。
- 默认方法名称改为任务语言：测网站与接口、查组件已知漏洞、研究组件安全更新。

### 🐛 问题修复

- 泛微/致远等中文产品不再错误匹配对方公告。
- `<=1.5.0` 不再被当成排他上界。
- `1.5.0-rc.1` 不再被当成正式 `1.5.0`。
- `task-policy-runtime` 改为自启本地服务，不再依赖外部靶场。
- 子角色启动/续跑复制父任务上下文时，会同时复制被引用的宿主执行回执；已有回执不再因跨会话查询失败要求模型重试，回执缺失则给出明确修复路径。

### ⚠️ 其他变更

- 结果插件升级到 `1.3.0`，数据库 schema 升级到 8，新增角色/工作/消息和上游映射表；旧库通过 `CREATE IF NOT EXISTS` 兼容升级。
- 对比实验继续暂停，旧结果不用于新版优势结论。

### ⚠️ 边界

- 任意循环和脚本控制流仍明确拒绝。
- 外部上游服务不可用、闭源或缺少可靠映射时返回具体缺口，不推定安全。
- 对比实验继续暂停。
- 不发布、不 push、不提交 Git。
