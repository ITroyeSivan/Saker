# Saker 0.9.37

### ✨ 新增功能

- 发现详情增加人工“依据复核”：可记录“依据足以支持 / 依据不足 / 已更正先前判断”，保存请求 ID 幂等、并发冲突可见，旧判断保留为“已更正”。
- 任务概览增加“隔天复核摘要”：最多三组、每组两个指针，分别显示待你复核、最新可核对记录和未确认的操作结果；只读、不补写费用事件、不重放请求。
- 执行记录增加“模型用量”视图：按账本归属和轮次汇总已知 tokens、传输尝试、已结算、未知、处理中和发出前撤销；未知不显示为 0，现金费用统一显示“未知”。
- 导出预览追加引用质量与人工复核计数，引用状态或复核决定变化会使旧快照拒绝下载。

### 🐛 问题修复

- 证据引用统一解析：`request:id:revision` 精确定位历史版本；裸 ID 只有在当前任务全部已知版本中唯一时才定位，否则显示“版本待确认”，不再默认选最新。
- 执行回执按服务端确认的归属和 ID 查找；子会话同名回执无法确认归属时显示待核，不默认借用。
- 材料索引存在但原件缺失时明确标为不可用，不伪造正文；发现详情不再把原始 `high`、`file` 作为最终展示词。
- 安装器把 11 个包复制到 `<DSH_HOME>/saker-desktop-artifacts/<profile>`，清理发布解压目录后日常 profile 仍能解析依赖；隔离 home 使用自己的持久目录。
- 回退预览检查 Saker 本地包和可验证摘要，缺包或摘要不符时在写入前拒绝。

### 🎨 体验优化

- 复核摘要把 `paused:needs-user`、`time_budget_exhausted`、`plan_complete` 等内部状态翻成可读文案，同时保留原始状态代码。
- 执行与用量里的真实传输记录（对象形式）正确显示“已观察”，不再误报“未观察”。
- 安装说明统一为 **10 个功能插件 + 1 个根包**，区分安装器接受版本与当前支持的 `0.2.2-rc.1`。
- 预算说明按 `task-policy.js` 实际默认值写成“非项目、无桌面覆盖时 15 分钟 / 60 次工具 / 48 次模型”，不再声称每个新会话固定 48 次。
- 明确 `build-info.json`、`packages.json` 在 ZIP 内，`LATEST.json` 与 ZIP `.sha256` 在 ZIP 外。
