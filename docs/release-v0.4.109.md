### ✨ 新增功能

- 新增「按文档测试」场景：直接读取 Word、Excel 和文本测试要求，按原文连续执行；结果按「文档要求 / 结果 / 说明」展示，区分发现问题、未发现问题、需进一步确认、缺少条件和未开始。
- 新增受管 Chrome for Testing 浏览器会话：打开、观察、点击、输入、选择、上传下载、弹窗处理和读取相关请求；路径可在「安全配置 → 工具 → Chrome for Testing」配置。
- 新增项目文档读取、检查记录、项目 HTTP 派发、连续接续与结果导出；模型侧提供 `project_document`、`project_check`、`saker_browser`、`project_request` 四个入口。
- 知识库开关与任务文档读取相互独立：关闭知识库只停止额外知识补充，不影响读取你交付的测试要求。

### 🐛 问题修复

- 修复同一次更新里更换目标并标记已修复时沿用旧目标证明的问题；目标、路径、身份或请求修订变化时整次回滚，普通标题编辑不受影响。
- 修复已修复记录接受与最新「无法确认」相矛盾更新的问题；显式提交 `fixed` 时要求最新复测为带正常功能对照的「本次未复现」。
- 修复项目任务状态读取被实战研究方向校验拦截的问题。
- 项目运行结束后可以再次开始，建立新运行并保留旧结果。
- 修复写操作断线后状态不明的问题：写方法超时或断线保留「结果未知」，恢复前拒绝盲目重发；只读请求不会被误标为未知写入。
