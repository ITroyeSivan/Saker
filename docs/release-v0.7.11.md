# Saker 0.7.11

本版压缩会话输入区上方的常驻信息，把重复范围、状态和用量收进单一任务详情。

### ✨ 新增功能

- 输入区上方改为一条紧凑操作栏，集中显示当前方法/阶段、任务状态、请求数、停止、提示词、附件和更多入口。
- 任务详情集中显示完整范围、目标、资产、请求/回执、运行助手、用量、诊断和本轮操作。
- 方法入口在运行中显示实际阶段进度，直接处理或未开始时保持简短状态。

### 🐛 问题修复

- 不再默认叠放任务状态、最近动作、范围摘要、两枚范围按钮、用量行和新建测试行。
- 长 URL、累计 token、零值和低频设置不再撑高输入区。
- 消息完成、停止或切换会话后，详情保持按需打开，不自动占用对话空间。

### 🎨 体验优化

- 常用入口保留在唯一状态栏；协作、设置和新建测试集中到“更多”。
- 窄窗口优先保留方法、状态和停止，附件与提示词可继续从菜单进入。
- 任务详情使用单一独立滚动面板，关闭后保留原对话位置。

### ⚠️ 其他变更

- 当前仍只支持 2–12 步线性方法；对比实验继续暂停。
- 本版不发布、不 push、不提交 Git。
