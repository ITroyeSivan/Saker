# Saker UI 拒绝冒烟 + 「转圈转不停」硬化（2026-09-19）

## 为什么要加这一档

上午那次的设置页冒烟只看了两件事：面板**非空**、`data-slot-error = 0`。
结果当天下午就出了一个漏网的 bug：知识库详情区**白板 + 卡在「保存中…」**——
面板非空、`data-slot-error` 也是 0，**旧冒烟全绿**。

根因是客户端 Promise 被 reject 后 `.then` 永不执行，`busy` 永远为 true。
这类"看起来在忙、其实已经死了"的状态，只有把 **未处理拒绝** 接出来才抓得到。

## 新增：UI 拒绝冒烟

工具：`_ref/tools/sweep-ui-rejections.mjs`（可复用，已进清理白名单）。

它逐个打开界面并同时盯三件事：

- `window.addEventListener('unhandledrejection', …)`
- `window.addEventListener('error', …)`
- 包装 `console.error`

覆盖：**11 个设置分区** + **9 个会话标签页**。

### 先证明它会失败（否则"没发现问题"没有意义）

在同一个页面里注入 `Promise.reject(new Error('sweep-selftest-expected'))`：

```
["unhandledrejection: Error: sweep-selftest-expected\n    at <anonymous>:1:22 …"]
```

钩子确实抓到了。**所以下面的全绿是真绿，不是假绿。**


20 个界面、零未处理拒绝、零 `console.error`、零 slot 错误。

## 顺带把整类问题收干净

### 1. 六个连接层 RPC 插件逐个核对失败形状

宿主连接层要求失败必须是 `{ok:false, error:{code,message,details}}`，
回字符串会被 `parseConnectionResponse` 判成 `invalid server-response result` 并 reject。

| 插件 | 失败形状 | 处理 |
|---|---|---|
| skill-browse | `failure()` 结构化 | ✅ 本来就对 |
| method-stack | `failure()` 结构化 | ✅ |
| sec-config | `failure()` 结构化（`probeUrl` 的字符串结果只作为 value 内嵌） | ✅ |
| mcp-studio | `ok()/failure()/badRequest()` 全结构化 | ✅ |
| knowledge-hub | 字符串 | 上一轮已修 |
| webshell-mgr | 字符串 | 上一轮已修 |

### 2. 「设了 busy 却没有拒绝处理」——扫出 5 处，补 4 处

静态扫 `set*Busy(true)` 之后 30 行内有没有 `.catch` 或 `.then(onFulfilled, onRejected)`：

| 位置 | 判定 | 动作 |
|---|---|---|
| knowledge-hub `read` / `write` / `remove` / `search` | 无拒绝处理 | **补 `.catch`**（清 busy + 显示失败原因） |
| sec-config `save` | 无拒绝处理 | **补 `.catch`** |
| mcp-studio `runDiagnose` | 用的是 `.then(f, r)` 双参形式 | 无需改 |

补的 catch 不只是"防协议错"：宿主重启、连接中断同样会让 RPC reject，
那时界面必须**把 busy 清掉并说明原因**，而不是无限转圈。

### 3. 加一条跨插件 lint 锁住这一类

`scripts/test-repo-hygiene.mjs` 新增断言：

> 设 busy 的 RPC 链都有拒绝处理（否则会卡在转圈）

它扫全部 `plugins/*/lib/client.js`，认 `.catch(...)` 与 `.then(onFulfilled, onRejected)`
两种写法。**同样先做了证伪**：

```
bad  -> flagged: true   (期望 true)
catch-> flagged: false  (期望 false)
2arg -> flagged: false  (期望 false)
```

以后谁再写一条只 `.then` 不 `.catch` 的 busy 链，回归会直接亮红。
