# Saker 模型思考强度真实验证（2026-09-19）

## 目的

验证此前“模型无法选择思考强度”的问题已在浏览器 UI 和真实模型请求两侧修复。

## 浏览器验证

CFT 打开真实会话后点击模型选择器，页面显示：

```text
模型
deepseek-flash
推理等级
Off

Default
Off
Low
High
Max
```

选择 `High` 后，输入区模型标识从：

```text
deepseek-flash · Off
```

变为：

```text
deepseek-flash · High
```

## 真实请求验证

在同一会话继续发送：

```text
只回复 HIGH_OK。
```

模型返回 `HIGH_OK`。

从会话 transcript 的 `request/header.config` 读取实际配置：

```json
{"provider":"custom","model":"deepseek-flash","reasoningEffort":"off","maxTokens":128000}
{"provider":"custom","model":"deepseek-flash","reasoningEffort":"high","maxTokens":128000}
```

第二条是选择 High 后的真实请求，证明不是只改 UI 标签。

## 结论

- 设置选项可见。
- 当前选择可切换。
- 会话状态正确保留。
- 真实模型请求携带 `reasoningEffort: "high"`。
- `data-slot-error = 0`。

本轮无需修补。
