# Saker 设置页全量烟测（2026-09-19）

## 目的

单元测试和 release gate 只能证明插件逻辑可用，不能证明真实宿主把 23 个插件的前端
面板都成功装配出来。本轮用隔离宿主 + Chrome for Testing 逐个切换全部设置面板。

## 方法

- 隔离 `DSH_HOME=_ref/dsh-home-test`
- 独立 CFT 实例与 profile，不使用用户日常 Chrome
- 1600x1000 视口
- 逐个点击左侧面板，等待 900ms 后读取：
  - `[data-slot-error]` 数量必须为 `0`
  - 面板关键文本是否出现
  - 可见控件数量

## 结果

| 面板 | slot error | 可见控件 |
|---|---:|---:|
| 通用设置 | 0 | 36 |
| 模型 | 0 | 32 |
| 插件 | 0 | 33 |
| Agent 预设 | 0 | 40 |
| 已归档会话 | 0 | 28 |
| MCP 工作台 | 0 | 58 |
| 安全配置 | 0 | 116 |
| 知识库 | 0 | 44 |
| 技能 | 0 | 39 |
| 方法编排 | 0 | 87 |
| WebShell | 0 | 161 |

关键面板已确认实际渲染：

- 模型：DeepSeek / opencode go / 添加提供方；
- MCP：Burp `27`、Yakit `149` 和三个 fixture 的状态卡；
- 安全配置：模型端点档案、统一出站策略和最近判定；
- 知识库：索引统计、自动同步状态、来源层与目录筛选；
- 方法编排：模块、整组启用、组合保存/应用；
- WebShell：模板库、已登记连接和文件目录。

## 结论

当前 11 个设置面板没有前端 slot 崩溃或空面板。该轮只做烟测，不修改配置；
CFT 与隔离宿主已在验证后关闭。
