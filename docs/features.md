# 功能说明

Saker 运行在官方 DeepSeek Harness Desktop。新建会话选择 **Saker 渗透测试**，再从聊天输入框上方选择任务方向。

## 按文档测试

添加环境说明和测试要求，模型读取后整理检查项，再调用工具逐项检查。本地支持 `.docx`、`.xlsx` 和文本；保留来源修订、段落或单元格位置，并显示解析提示。环境与要求不必拆成固定格式；无法直接读取的云文档可先导出或粘贴正文。

文档只有一个网站时，开始测试会自动识别主目标；包含多个网站时，在测试设置里指定本次测试网站。其他 API、登录或静态资源站点可填入“其他允许访问的网站”。模型发现新地址不会自动扩大访问范围。只分析文档时，关闭“允许访问网站”。

运行期间，对话上方直接显示当前运行、已完成数量、当前检查和问题数，并提供暂停、继续、查看检查表、历史运行和导出入口。检查表按“文档要求 / 结果 / 实际做了什么或缺什么”展示；缺少账号、测试对象或其他条件的项目单独记录原因。查看和刷新只读取本地记录，不调用模型或访问目标。

暂停和重新启动应用会保留进度与已用额度。连接中断时，若不能确定原写操作是否生效，界面会列出需要核对的操作；核对前不会继续请求，确认已生效的相同操作不会重复提交。“结束本次”保留已有资料和结果，再次测试建立独立记录。导出文件包含已保存的来源与执行材料；截图和下载附件保留原始内容，分享前请核对业务数据。

## 常规测试、Nday 发现与 0Day 挖掘

| 方向 | 用途 |
| --- | --- |
| 常规测试 | 根据提供的业务和账号，比较角色、对象、参数及操作步骤 |
| Nday 发现 | 根据产品与版本线索查阅相关公开漏洞，核对适用条件 |
| 0Day 挖掘 | 沿具体疑点分析页面、JS、接口及可用源码，再验证实际行为 |

三种方向共用当前任务的资料与记录。只有目标地址时可以先做信息收集；已有账号、接口或报文时可以直接开始。资产查询和扫描工具需要单独配置。

## 聊天输入框上方的入口

| 入口 | 如何使用 |
| --- | --- |
| 提示词模板 | 搜索一个需求示例，修改目标和重点，复制或插入输入框；插入不会自动发送 |
| 添加测试资料／添加测试文档 | 保存本次任务的文件或已有内容；项目方向使用文档入口 |
| 测试设置 | 查看目标、访问限制、预算等任务设置；实战方向还可调整协作方式和助手数量 |
| 知识库 | 开启或关闭本任务的相关知识读取；任务文档与通用知识分开保存 |

模板由用户选择和编辑，不作为每轮强制执行的长流程。知识库保留产品资料、漏洞条件和个人笔记，按相关内容查阅；不开启整库注入。已保存资料只有被读取并进入模型输入时，才会占用相应上下文。

## 浏览器与外部工具

浏览器使用独立 Chrome for Testing，通过 CDP 操作页面和读取请求。路径在 **应用设置 → 安全配置 → 工具** 中配置。Burp、Yakit 及其他 MCP 服务在 **MCP 工作台** 配置，服务需另行启动。

实战任务可按需要使用子代理，上限以宿主实际支持范围为准。短任务可由主代理直接处理，不要求固定分派多个代理。

## 到哪里查看结果

- **执行记录**：工具和模型调用，以及已保存的 HTTP 回执。
- **发现的问题**：问题说明、复现材料、复核状态和缺少的证据。
- **测试资料**：添加的文件、报文、JS 和其他已有内容。
- **任务用量**：模型调用、Token、工具用量和运行时间。

“未发现问题”只针对记录中的检查范围；“需进一步确认”“缺少条件”和“部分完成”保留未覆盖内容。判断是否成立仍需核对实际请求、身份和业务结果。
