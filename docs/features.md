# 功能说明

Saker 运行在官方 DeepSeek Harness Desktop。新建会话选择 **Saker**，再从聊天输入框上方选择 **自由测试**、**比赛模式** 或 **案例测试**。

## 比赛模式

题目可以来自题面、附件或实例。题目列表最多返回 50 条摘要，详情单独读取；附件按题目保存，同名文件不会串到其他题目。Host 命令在题目独立目录中运行，每次执行有自己的 stdout/stderr 和字节游标。Docker 仅在本地 daemon 可用、镜像已在本地且平台为 `linux/amd64` 时运行；程序不会自动拉取镜像，发布包也不自带 Docker 环境。

模型保存的只是候选答案。候选原文不做 trim、大小写转换或编码改写；“已通过”只能由用户或平台确认。输出中出现示例 flag 不会自动结束比赛，也不会触发旧 CTF 观察器。

本地资料默认关闭。开启后可按关键词搜索并分段读取固定修订；关闭时不声明检索工具，也不把资料库 schema 或摘录注入请求。

## 案例测试

添加环境说明和测试要求。本地支持 `.docx`、`.xlsx` 和文本；表格中可识别的表头和后续数据行会在开始时由程序直接形成检查项，不规则文档保留原文供模型正常分析。来源修订、段落或单元格位置和解析提示会保留；无法直接读取的云文档可先导出或粘贴正文。

文档包含一个或多个网站时，开始测试会保留识别到的入口范围；其他 API、登录或静态资源站点可填入“其他允许访问的网站”。模型发现新地址不会自动扩大访问范围。只分析文档时，关闭“允许访问网站”。

运行期间，对话上方显示当前运行、进度与问题数，并提供暂停、继续、查看检查表、历史运行和导出入口。检查表以弹窗展示“测试要求 / 执行情况 / 结论 / 结果说明”，长说明通过详情读取；缺少账号、测试对象或其他条件的项目单独记录原因。进度自动刷新，历史加载期间锁定操作；查看和刷新只读取本地记录，不调用模型或访问目标。

暂停和重新启动应用会保留进度与已用额度。连接中断时，若不能确定原写操作是否生效，界面会列出需要核对的操作；核对前不会继续请求，确认已生效的相同操作不会重复提交。“结束本次”保留已有资料和结果，再次测试建立独立记录。导出文件包含检查引用的文件、来源、命令、HTTP 和浏览器依据；删除的材料会明确列入缺失清单。截图和下载附件保留原始内容，分享前请核对业务数据。

## 范围、资产与执行

“目标、范围或已有材料”接受完整 URL、多行 URL、域名、`*.example.com`、IP、IPv4 CIDR 和资产清单，也接受用自然语言说明的排除项。用户原始要求、起始路径、参数和材料引用会保留；程序再用一条可编辑的理解结果展示包含与排除范围。

同一任务中，用户可在设置里调整范围、研究重点、时间或剩余额度。聊天里提出的扩大范围、提高额度或放开权限会形成一条待确认变更；它不会由模型、网页或文档自动生效。确认后沿用原任务、证据和累计用量，不重置账本。

自由测试的普通探索可以直接执行，程序保存实际请求、响应、来源和入口，不再要求每个请求先有方法、基线或研究方向。计划内的正常/异常对照和完整影响证明仍是形成正式漏洞结论所需，不是普通探索的准入门槛。

案例检查可以使用文件、来源、本地命令、HTTP 回执或浏览器观察作为实际依据。程序从真实调用自动保存事实和可见结论，不要求模型另行登记。每项保留实际观察与说明，来源与本次运行对应；尚未读取的内容不会被当作已确认依据。

FOFA 原生查询和被动候选整理不向候选主机发请求，不依赖测试网站或“未计量扫描额度”。首轮查询、后续过滤、结果总数、已获取数、游标和失败原因会保留；还有下一页或配额不足时不会显示“已搜完”。

## 常规测试、Nday 发现与 0Day 挖掘

| 方向 | 用途 |
| --- | --- |
| 常规测试 | 根据提供的业务和账号，比较角色、对象、参数及操作步骤 |
| Nday 发现 | 根据产品与版本线索查阅相关公开漏洞，核对适用条件 |
| 0Day 挖掘 | 沿具体疑点分析页面、JS、接口及可用源码，再验证实际行为 |

三种方向共用当前任务的资料与记录，只是研究重点，不锁定工具、助手对象或执行顺序。只有目标地址时可以先做信息收集；已有账号、接口或报文时可以直接开始。资产查询和扫描工具需要单独配置。

## 聊天输入框上方的入口

| 入口 | 如何使用 |
| --- | --- |
| 写提示词 | 搜索一个需求示例，修改目标和重点，复制或插入输入框；插入不会自动发送 |
| 添加文件／添加题目／添加案例 | 按当前场景保存已有内容；本地查看和导入不会自动调用模型 |
| 设置 | 设置目标、访问限制、身份、预算、方向、协作方式、汇报方式和助手数量；修改先存草稿，保存后生效 |

模板由用户选择和编辑，不作为每轮强制执行的长流程。公共知识库已退出产品；CVE、公告、仓库和 EXP 需要时直接联网或用现有文件读取。已保存资料只有被实际读取并进入模型输入时，才会占用相应上下文。

## 浏览器与外部工具

浏览器使用独立 Chrome for Testing，通过 CDP 操作页面和读取请求。路径在 **应用设置 → 安全配置 → 工具** 中配置。Burp、Yakit 及其他 MCP 服务在 **MCP 工作台** 配置，服务需另行启动。

实战任务可按独立问题使用子代理，可指定一个或多个已授权资产以及不同研究重点；父子任务共享总预算、取消和写操作归属。短任务可由主代理直接处理，不要求固定分派多个代理。

浏览器打开页面时，允许正常加载范围内的页面和公开静态依赖；外域脚本、样式、图片等不会因此成为主动测试对象。跨域 API、XHR 和主动验证仍按用户范围检查，身份秘密按 origin 和账号绑定。

## 到哪里查看结果

- **执行记录**：工具和模型调用，以及已保存的 HTTP、比赛进程和交互输出。
- **发现的问题**：问题说明、复现材料、复核状态和缺少的证据。
- **测试资料**：添加的文件、报文、JS、题目附件和其他已有内容。
- **任务用量**：模型调用、Token、工具用量和运行时间。
- **当前任务状态**：范围、排除、重点、资产总数、已处理、正在验证和待确认数量；“查看资产”支持本地筛选和分页。

“未发现问题”只针对记录中的检查范围；“需进一步确认”“缺少条件”和“部分完成”保留未覆盖内容。判断是否成立仍需核对实际请求、身份和业务结果。
