# Saker 0.7.8

本版补齐方法选择、阶段预览和简单编辑，让默认工作流既可以直接用，也可以按本轮任务调整。

### ✨ 新增功能

- 输入区新增“方法”，可查看内置方法、七套默认做法和已保存的个人方法。
- 支持用阶段图查看每一步要做什么、会留下什么；内置方法可以直接使用，也可以复制后编辑。
- 支持新增、删除、上下移动步骤，编辑步骤说明、工具和完成条件，并提供撤销/重做。
- 支持“只用这一轮”和“另存为我的方法”；本轮编辑不会修改内置方法，也不会污染个人方法库。
- 七套默认方法覆盖测网站、查已知漏洞、从软件更新找问题、单题、多题、按要求逐项验证和历史复测。

### 🐛 问题修复

- CTF 会话默认落到单题方法，不再错误地使用网站测试方法。
- 方法选择会进入下一真实回合的上下文，模型先用 `saker_workflow` 取得选定方法的当前步骤。
- 自定义方法的保存、读取、选择和删除使用同一份定义和来源，不把会话内草稿冒充个人方法。

### 🎨 体验优化

- 方法面板默认显示紧凑列表和阶段预览，只有需要修改时才进入编辑状态。
- 编辑器使用“做什么、还需要什么、会用哪个工具、完成后留下什么”的任务语言。
- 保存后不会自动发送消息；用户仍决定什么时候开始、什么时候提交。

### ⚠️ 其他变更

- 需要 Node.js 24.9 或更高版本；当前适配官方 Desktop 0.2.2-rc.1。
- 本版不发布、不 push、不提交 Git。
