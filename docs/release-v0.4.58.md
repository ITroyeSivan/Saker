# Saker v0.4.58

## 发布重点

本版围绕护网授权测试的效率重整渗透测试入口：提供常规测试、Nday 发现、0day 挖掘三种可组合、可自定义的提示词模式；默认避免无差别运行多种扫描器。目标范围止于获得可复现的 RCE。

## 变更

- **三种渗透子模式**：把常规测试、Nday 发现、0day 挖掘作为独立可选组合；精简常驻提示词，CTF 不再占用默认新会话入口。
- **Nday 来源与匹配**：按产品、版本和公告时间检索厂商公告及 CVE、CNVD、CNNVD、AVD。没有 CVE 编号时仍查询中文漏洞库；确认版本与前置条件后再查具体利用资料，不随包堆积大批 PoC。
- **扫描器按需启用**：Nmap、目录探测、Nuclei 等工具通过会话工具包加载；回合结束可卸载，避免每个会话默认暴露整套扫描工具。
- **资产与验证留痕**：改进资产清单、指纹/Nday 交接、证据索引和阶段门禁，并修正若干宿主兼容、提示词注册、自动推进及设置读取问题。
- **其他插件修复**：更新工具隔离、技能注册、模型思考配置、知识库检索与 MCP Studio 等组件及对应回归测试。

## 验证

- 全量回归：46 套 · 13,185 通过 · 0 失败 · 16 跳过。
- 渗透子模式选择与默认会话入口：CFT 实际 UI 验收通过；新会话没有自动插入聊天内容。
- Nday 检索：隔离 DeepSeek 官方路由、`deepseek-flash`、思考关闭，完成受限模型回合；模型查询两次目录工具并识别条目及配置前置条件。
- 扫描工具包：CFT 实际调用工具包加载/卸载；初始工具表 46 项，加载后增加 8 个扫描工具，卸载后恢复。该回合未运行扫描器或访问目标。
- 扫描工具、提示词、CNVD/CNNVD 查询规则及安装一致性通过各自回归；隔离 profile 同步检查为 2,261 个文件 / 24 个插件。
- 工作台探针：10/10 通过。文档版本检查、临时目录边界检查通过。

## 尚未验证与已知限制

- **没有进行 SRC 实战测试**；目标验证由用户后续进行。
- 本地合成场景和单条本地 Tomcat 链路不等同于真实产品指纹到 RCE 的完整效果验收；常规与 0day 模式的对照效果仍未完成。
- 扩展发布门禁未全绿：知识索引为 604.6 MB，超过 600 MB 门槛；当前真实 DSH profile 与本次源码版本不同步。本次发布不覆盖用户本机 profile。
- 因上述限制，本版测试结果不构成“无任何缺陷”或真实目标成功率保证。

- Node.js `>=22.5`
- 全量回归与浏览器验收使用隔离 profile；模型验收使用 DeepSeek 官方路由的 `deepseek-flash`。
