# Saker 0.9.30

### ✨ 新增功能

- 工作台查询按完整范围键隔离：root、generation、筛选和页码变化时不再把上一个范围的数据当成当前范围。
- 任务、发现、流量、资产、执行、待处理、运行记录增加搜索、筛选、分页和“当前加载 / 总数”显示。
- 流量行、资产行、图节点可以打开真实执行详情、请求/响应原文和关联检查；探索图与覆盖图支持搜索、缩放、平移、图例和关系箭头。
- 能力库新增收藏/最近视图、子类导航、复制修改和另存为个人模块；旧“测试方法”并入“我的组合”。
- 角色库改为默认浏览与搜索，详情显示版本、当前实例，可复制新版本、保存个人角色并选择工作项派工。
- 工作台新增“参考资料”入口，按任务读取项目资料正文。

### 🐛 问题修复

- 修复跨 root 同名局部 ID（如两个 F001）在发现表中复用同一个 React key 的问题。
- 修复模块详情、会话快速搜索的迟到响应覆盖新选择的问题；详情按选择序号接收。
- 修复未知命令重试生成新 commandId 的问题：保留原 ID，先查 `command.status`，确认未受理才复用同一 ID。
- 去掉未选择任务时自动取第一条 root 的兜底；全局页显式显示范围，日志和工具页必须先选任务。

### 🎨 体验优化

- 内导航改为语义图标并支持手动收起；窄容器自动收起，模块分类在窄区转为紧凑筛选。
- 模块完整说明、输入输出 JSON 收进“高级”折叠区；角色库不再把创建表单放在默认首屏。
- 成功/提醒/危险状态改为亮暗自适应 token，暂停徽标提高对比；网络错误说明失败对象、范围和旧数据是否保留。

### ⚠️ 其他变更

- `@dsh-external/dsh-redteam-results` 升到 `1.4.23`，根包 `0.9.30`。
- 新增工作台范围/异步与 120 条列表分页回归。
- 不改变用户数据、MCP、会话、知识与个人方法；未发布、未 push、未提交 Git。
