# Saker 0.9.3

本版修复同一 workbench 命令在多个 Desktop 窗口同时提交时可能重复执行的问题。

### ✨ 新增功能

- 同一 `commandId` 的并发提交会共享一个 in-flight 结果。

### 🐛 问题修复

- 修复两个窗口同时发送同一 `commandId` 时两边都可能执行一次副作用的问题。
- 内容不同但复用同一 `commandId` 的请求仍明确拒绝，不会被当成重复提交。

### 🎨 体验优化

- 第二个窗口等待第一个窗口的真实结果，不显示另一套成功或失败状态。

### ⚠️ 其他变更

- 结果插件升级到 `1.4.3`；命令、任务、角色和回执数据保持兼容。
- 对比实验继续暂停；0.7.6 的历史结果仍为双方 64/72、McNemar p=1.0，没有成功率优势。

### ⚠️ 边界

- 本版解决同一 Host 进程内多窗口并发；跨进程数据库锁仍以 commandId 冲突/查询处理。
- 不发布、不 push、不提交 Git。
