### ✨ 新增功能

- 本轮任务可设置共享模型调用上限；主代理、所属子代理、宿主重试、压缩和标题生成共同使用额度。持久账本在调用前预留、发出前标记、结束后结算。
- 聊天“设置 → 开始任务与预算”可在首次生成前启动有额度的任务，无需先让模型创建任务。

### 🐛 问题修复

- 额度耗尽在提供方调用前拒绝，桌面显示原因；未知用量不会当作零，也不能释放可能已发出的调用。
- 进程退出后只释放确定未发出的预留，发出但未结算的调用保留未知。重启不重置任务额度；同时领取通过 SQLite 事务约束。

### 🎨 体验优化

- 任务详情显示共享模型额度及剩余次数，区分会话生成记录与实际准入账本。后台标题用量也能归入本轮。
- 保留精简入口及常规/Nday/0Day，不恢复已删除模块；开始按钮在聊天设置中保持可见对比度。

### ⚠️ 其他变更

- 严格 token 模式需要匹配完整实际请求及调度的可靠计数。当前生产路线未接入该能力，因此拒绝严格请求，不把估算或输出上限称为硬 token 预算。
- 官方 Desktop 实测：1 次额度生成消耗 17,876 token，后续请求被拦截；另一会话主生成 17,889 token、标题 176 token，共占 2 次额度。100 token 严格请求因无可靠计数被拒绝。这些是预算流程验收，不是漏洞效果实验。
