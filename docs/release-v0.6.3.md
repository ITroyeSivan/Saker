# Saker 0.6.3

本版完善 DeepSeek Harness Desktop 0.2.2-rc.1 的助手调用、动态工具加载和执行记录，并调整比赛模式表单。默认继续使用原生工具调用。

### ✨ 新增功能

- 本次为维护更新，沿用自由测试、案例测试和比赛模式三个场景。

### 🐛 问题修复

- 修复启用 PTC 时助手缺少 `run_code` 入口、无法读取文件或执行命令的问题；业务工具继续受原有准入规则约束。
- 修复运行中新增工具未按工具包收起的问题，补齐刷新期间再次注册工具的处理，保持加载和收起状态一致。
- 补齐 PTC 嵌套工具的执行记录与调用统计，保留父子关系；取消后的调用正确显示为取消。
- 移除比赛和代码分析预设中的失效宿主组件引用，恢复会话创建。
- 修复比赛题目表单标签与控件错排；题面、地址、连接说明和 Docker 镜像字段按行显示，长内容在面板内滚动。
- 修正比赛题目详情的标题边距，消除多余的横向滚动。

### 🎨 体验优化

- 重新组织 README，将设计理念、使用场景和具体功能结合介绍，保留多张功能图片。
- 更新比赛模式图片，展示当前界面；公开图片使用示例资料，隐藏日常会话与个人信息。
- 比赛表单共用字段样式，题目详情中的命令和答案输入保持一致的布局。

### ⚠️ 其他变更

- 需要 Node.js 24.9 或更高版本；当前适配官方 Desktop 0.2.2-rc.1。
- PTC 继续作为需要显式启用的可选方式；其代码执行环境不作为完整的目标范围沙箱。
- 更新沿用原有会话、账号、个人模板与 MCP 配置，安装前自动备份，并刷新桌面启动快捷方式。
