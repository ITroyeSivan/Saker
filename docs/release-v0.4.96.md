### ✨ 新增功能

- 工具库增加“检查启动”：对已保存工具实际运行固定帮助或版本参数，区分缺失、启动失败、未支持与可启动，提供修正依据。

### 🐛 问题修复

- 修复聊天快捷栏与输入框宽度不同、常规测试等控件未对齐的问题，跟随宿主宽度调整。
- 当前成果的列表、分组与导出限定本会话，避免历史记录混入本轮；修复历史页显示本会话交付入口的范围混淆。
- 修复启动检查误读 Desktop RPC 包装、后台成功但界面显示失败的问题。

### 🎨 体验优化

- “redteam 成果”改为“任务与成果”，按任务、发现、资料、历史组织，默认折叠用量和统计，资料及历史按需打开。
- 默认显示待验证与已验证记录，保留原有独立验证和交付规则。
- 快捷控件统一高度，协作设置和提示词面板与输入框保持对齐。

### ⚠️ 其他变更

- 官方 Windows Desktop 0.2.0-rc.2 实际验收，95 套回归、13,661 通过、0 失败、16 跳过。16 项本机启动检查中 10 可启动、4 入口缺失、2 尚未支持；帮助成功不证明目标操作或模型工具已加载。
- 页面操作未增加模型请求，专用 transcript 哈希不变；工具定义仍有上下文开销，本版不宣称 token 节省或漏洞发现效果提升。
- Desktop 快捷方式已刷新并实际启动，日常配置保留；两项 MCP 仍未连接。其他插件顶层页及 G0–G10 完整目标继续改进。
