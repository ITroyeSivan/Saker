# Saker 0.7.0

本版把任务设置、知识查询和资料整理收敛到可验证的统一入口，修复草稿额度丢失、比赛隐藏字段误提交、设置部分成功和知识关闭仍可能读取资料等问题。

### ✨ 新增功能

- 任务设置使用统一 `task.settings` 协议：版本冲突、轮次冲突、幂等请求、字段白名单和一次事务提交。
- 设置页拆成“范围与账号 / 知识查询 / 用量限制”，协作、文件、提示词和设置各自拥有独立面板。
- 草稿中的时间、工具、模型、token 和未计量额度会继承到自然语言启动、按钮启动、案例与比赛执行。
- 比赛普通偏好不再携带网站字段、不再递增场景版本，也不会在保存时提前消耗运行时间。
- 知识库恢复本地词检索、中文双字、产品/版本、CVE 与路径约束，支持联网优先、本地优先和仅本地三种策略。
- `saker_material` 统一附件与参考资料：搜索最多 5 条且不超过 3072B，正文按 8192B 分段读取。
- 回答/发现旁新增“整理为知识”；一次点击最多一次 provider wire，无工具、无自动续接，结果先进入可编辑草稿。

### 🐛 问题修复

- 修复 U01：保存 7 分钟后重开变空；新设置从持久库读回，启动路径继承同一上限。
- 修复 U02：比赛只改汇报仍携带隐藏网站参数被拒绝；现在只提交本场景真实变化字段。
- 修复 `allowedOrigins` 保存后再发第二次 `task.limits` 可能部分成功的问题。
- 修复降低助手上限被已有助手阻塞；现在只影响后续派发，不终止现有助手。
- 修复保存成功后刷新被保存状态挡住，导致后续设置继续使用旧基线的问题。

### 🎨 体验优化

- 设置窗口按可用视口调整宽高，标题与保存区固定，仅正文滚动；窄窗切换为可滚动横向标签。
- 协作、文件、提示词和设置互斥打开，关闭后焦点回到原入口，未保存的非秘密草稿保留。
- 知识搜索结果明确显示来源、章节、修订与适用性；读取正文按 UTF-8 字节分页，避免半个汉字。

### 🔐 边界

- 知识查询默认关闭；关闭时在读取索引、缓存或原文之前返回 `knowledge_disabled`。
- 取消整理不会撤销已经发出的外部请求；未知费用保留为 unknown，不伪造成 0。
- 独立整理只在那次点击中运行，不自动续接测试；本地模型离线时不会切换到云端。

### ⚠️ 其他变更

- 需要 Node.js 24.9 或更高版本；当前适配官方 Desktop 0.2.2-rc.1。
- 更新沿用原有会话、账号、个人模板、任务历史和 MCP 配置；安装前自动备份并刷新桌面快捷方式。
