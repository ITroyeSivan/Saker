> 0.4.110–0.4.112 的集中更新说明见 [最新发布页](https://github.com/ITroyeSivan/Saker/releases/tag/v0.4.112)。本版本标签和安装附件保留。

### ✨ 新增功能

- “按文档测试”现在可以从聊天顶部直接进入。Word、Excel 和文本会在本地解析，并保存来源、修订、真实段落位置与不可读提示。
- 项目来源现在区分未读、读过但未整理、测试要求、参考材料和无法读取区域。模型需要保存真实整理决定后才能进入收尾。
- 项目检查结束后会自动同步完成、等待条件或暂停状态；独立项继续推进，缺少账号或对象时单独保留缺口。
- `project_request` 的模型返回现在包含有限响应正文、业务头和执行回执引用，不用再依赖缺失请求头的 shell curl 猜测业务结果。

### 🐛 问题修复

- 修复部分 Windows 环境设置 SOCKS `ALL_PROXY` 后，官方 Desktop 宿主在启动阶段退出的问题。启动器保留 HTTP/HTTPS 代理，只移除 dsh 暂不支持的 `ALL_PROXY`。
- 修复项目检查全部结束后仍显示“本轮进行中”的状态缺口。
- 修复没有检查项的空计划可以被当成完成、未读来源可以被检查结果掩盖的问题。
- 修复项目文档列表只显示少量段落、读取结果缺少来源和续读信息、文档读取没有计入实际进展的问题。

### 🎨 体验优化

- 聊天任务方向增加“按文档测试”，添加文档、开始任务、查看项目状态和结束结果使用同一条入口。
- 项目准备阶段会明确提示继续读取或整理来源，不再因为模型提前结束回复而长期停在准备中。
- README 重新设计，以真实项目面板为首页视觉，突出按文档执行、连续推进、真实浏览器和证据交付。

### ⚠️ 其他变更

- 版本更新到 0.4.110；`dsh-redteam-results` 升级到 1.0.181。
- 适用于官方 Windows Desktop 0.2.1-rc.2，同时兼容 0.2.0-rc.2；更新沿用原用户数据、会话和 MCP 配置。
