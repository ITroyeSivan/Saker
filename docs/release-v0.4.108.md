这一版集中调整了 Saker 的使用方式：从聊天中说明问题，带上已有请求或代码，选择需要的测试内容，再按需查知识、调用工具和分派助手。常用操作集中到聊天入口，减少固定流程、重复读取和无关界面。

### ✨ 新增功能

- **统一测试资料入口**：集中保存请求、响应、HAR、curl、JS、代码、扫描结果和资产清单，支持筛选、搜索、原文查看与引用。已有资料足够时直接开始分析；导入和浏览不会启动模型或访问网站。
- **重做提示词模板库**：36 篇模板按开始测试、信息收集、已知漏洞、深入研究、分析资料、结果与继续分组。填写少量关键信息即可编辑全文、复制、插入聊天或保存为个人模板，由用户决定发送内容。
- **整理发现与复测记录**：发现集中展示入口、身份、影响、复现步骤和原文依据；复测单独保存版本，区分“仍可复现”“本次未复现”“无法确认”，方便前后对照和后续补充。
- **打通知识检索与当前任务**：根据产品、漏洞和当前问题读取少量相关知识，查看本任务使用的条目；知识库与本次请求、代码等测试资料分开管理，关闭知识后停止新的读取。

### 🐛 问题修复

- 修复官方 Desktop 0.2.1 下部分工具定义导致 Saker 加载失败、资料导入出现 JSON 解析异常的问题；接口失败时给出具体错误，避免整块面板只剩加载提示。
- 修复面板无法用 Esc 关闭、模板插入位置不准确、资料显示内部文件名等操作问题。
- 修正助手人数限制、工具初始化失败、任务归属与释放处理；复核和报告读取所属任务的资料，报告助手只整理已有内容。
- 补齐失败、取消和无回执动作的执行记录，主任务用量包含所属助手；MCP 目标访问继续遵守范围、停止和用量设置。
- 移除统一的“15 分钟后证据作废”规则，改为核对请求、身份、目标实例和内容是否仍适用；复测留档与字段更新采用事务提交，留档时间由服务器记录。

### 🎨 体验优化

- **聊天入口收拢为四项**：提示词模板、添加测试资料、知识库、本次测试设置。面板统一开关方式，调整控件对齐、字号和信息密度，减少大块空白与抽象说明。
- **任务设置更直接**：在当前会话调整目标、账号、何时询问、何时汇报、是否解释原理及助手人数；保存后生效，可将通用选项存为默认偏好。
- **测试内容由用户筛选**：常规测试、Nday 发现和 0Day 挖掘共用资料与设置，默认选择 17 项 Web 核心内容，保留子域名和端口收集；可排除不需要的方向，CORS 与开放重定向默认不检查。
- **减少常驻提示词**：主要依靠模型能力和用户输入，不再默认附加整套方法步骤；模板由用户选择，资料与知识按需读取，工具的详细说明按需查看。
- **助手按需参与**：默认“自动，最多 2 个”，人数按宿主支持范围选择；站点分析、独立复核和报告整理共用人数限制，减少重复分派。
- README 改为完整功能介绍，补齐测试资料、发现列表和发现详情等图片，并更新安装及升级说明。
