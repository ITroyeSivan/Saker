# Release 说明格式

发布说明沿用 [v0.4.88](https://github.com/ITroyeSivan/Saker/releases/tag/v0.4.88) 的格式。标题为 `Saker v<版本号>`；正文不重复一级版本标题，按以下顺序使用三级栏目，每项以简短列表描述用户可见的变化：

```markdown
### ✨ 新增功能

- 本版新增能力。

### 🐛 问题修复

- 具体问题和修复后的行为。

### 🎨 体验优化

- 使用流程、界面或效率上的变化。

### ⚠️ 其他变更

- 实际验证范围、兼容情况和仍未完成的限制。

下载桌面安装包后，按 [安装说明](版本对应链接) 更新。具体操作、测试结果与限制见 [发布检查](版本对应链接)。
```

某栏没有相应变化时直接说明，不编造功能或修复。保留各版本真实的测试结果与未解决项；接入冒烟、设置上限、传输字节和测试断言不能写成漏洞效果、并发能力或费用改善。

正文源文件为 `docs/release-v<版本号>.md`，GitHub release 直接采用该正文；安装和验收链接指向对应版本的实际文件。修改历史说明只更新名称与正文，保持标签、发布状态、安装包及其哈希不变，不重写历史验证结论。
