# Release 说明格式

标题为 Saker v<版本号>，正文按以下顺序描述用户可见的变化：

```markdown
### ✨ 新增功能

- 新能力及用途。

### 🐛 问题修复

- 具体问题和修复后的行为。

### 🎨 体验优化

- 界面、操作流程或效率的变化。

### ⚠️ 其他变更

- 兼容性、迁移注意事项和产品限制。
```

没有变化的栏目可写「无」。正文不包含测试数量、运行结果、验收截图、开发对话、内部目标或开发记录链接。适用版本及真实功能限制可以保留，不夸大能力。

正文源文件为 docs/release-v<版本号>.md。更新历史发布说明仅修改正文，保留标签、发布状态和附件。安装包仅携带用户文档白名单。
