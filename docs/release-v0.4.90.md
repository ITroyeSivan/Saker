# Saker 0.4.90

聊天栏改为紧凑入口，移除自定义动画。原「交互频率」拆为「协作方式」与「进度汇报」：共同研判、关键节点确认、自主推进；汇报量独立选择。共同研判的等待节点可直接补充业务怀疑，再按这个思路继续。

子代理支持0–16的整数及常用人数快捷选择；所有未释放的代理完整显示，并继续共用原预算。同站复用、原等待状态和已有资料保留。

提示词增加「补充我的思路」模板，明确观察事实、业务背景与怀疑点；JS模板与真实任务提示词落实分段覆盖、证据迭代和支持/反证。
