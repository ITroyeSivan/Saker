# Saker 0.9.11

### ✨ 新增功能

- 模块列表与详情新增真实能力投影：区分可用、部分可用、缺少能力，并列出已验证 Host 工具、已解析二进制和缺项。
- 模块库支持按来源、能力状态和工具名筛选；快捷选择器支持分类与状态筛选。
- 新增 `project.files` 只读查询，报告与复现材料从真实会话工作区读取，不再依赖旧 stage-gate Web 通道。
- `saker_test_module begin` 在缺少关键能力时返回 `canExecute:false` 和真实缺项，不创建活动调用。
- 发现详情展示结论、影响、复现、请求/响应、依据引用和执行回执；可从详情直接定位实际回执，而不是把 requestId 当回执 id。
- 终态任务允许一次“只读解释”模型回合：自动剥离全部工具、不恢复执行许可、不新增目标请求，并单独标记 `read-only-qa` 用量。

### 🐛 问题修复

- 修复模块“有定义但无能力状态”的假完整。
- 修复报告文件页仍调用 `/dsh-stage-gate-project` 的旧依赖。
- 修复缺少后端 schema 时把模块误判为 blocked 的问题；此时显示“未探测”，不阻塞测试。
- 修复工作台发现详情查询把 camelCase Finding 对象当数据库行使用、导致详情 400 的问题。
- 修复发现详情卡只挂在全局视图、任务内“发现”页看不到详情的问题。
- 修复 `module.prefer` 在工作台模块页丢失真实 Host 会话、写入空归属偏好的问题。

### 🎨 体验优化

- 模块卡片显示能力状态、工具摘要和缺项，而不是只显示名称/版本。
- 详情页增加“优先用于下一项”，明确只影响下一次适用工作。
- 退役三个重复产品包：旧自动续接、旧会话状态页、外部 CLI 子代理 provider；源码与测试保留。

### ⚠️ 其他变更

- 根包升级到 `0.9.11`，结果插件升级到 `1.4.9`。
- 产品插件从 16 个减到 12 个；stage-gate 与 sec-enforce 因审计技能/硬守卫迁移尚未完成，暂保留。
- 不改变数据、MCP、会话、知识与个人方法。
- 对比实验继续暂停；不发布、不 push、不提交 Git。
