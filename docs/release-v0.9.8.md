# Saker 0.9.8

本版把工作台字号恢复到正常阅读尺度，跟随 Windows 与官方 Desktop 的默认显示比例。

### ✨ 新增功能

- 工作台正文、表格、按钮统一为 14px，辅助说明为 13px。
- 字号不再使用 11px/12px 的压缩写法，长内容与窄窗口下仍保留可读性。

### 🐛 问题修复

- 修复工作台比官方 Desktop 其他界面明显偏小、用户看起来吃力的问题。
- 修复任务详情、执行记录、方法面板、资料与提示词面板中的局部小字。

### 🎨 体验优化

- 不强制 `--force-device-scale-factor`，完全跟随 Windows 显示设置。
- 默认观感与官方 Desktop 其他界面保持一致，不需要用户调整系统缩放。

### ⚠️ 其他变更

- 根包升级到 `0.9.8`，结果插件升级到 `1.4.6`。
- 对比实验继续暂停；0.7.6 的历史结果仍为双方 64/72、McNemar p=1.0，没有成功率优势。

### ⚠️ 边界

- 不修改 Windows 系统缩放，不影响其他应用。
- 不发布、不 push、不提交 Git。
