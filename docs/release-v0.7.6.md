# Saker 0.7.6

本版处理 0.7.5 复核发现的 J01/J02，作为最后一轮迁移一致性收口。

### ✨ 新增功能

- 旧比赛资料投影会记录“源根会话 + 原 sourceId”身份，不同旧会话的同名资料不再相互覆盖。
- 删除旧资料投影时会映射回原来源，避免删除后又从旧表重新出现。

### 🐛 问题修复

- 迁移判等现在比较适用条件、来源、验证状态、许可和实际源日期；语义不同会保留双方并记录冲突。
- 仅导入时间等技术字段不同的重复资料仍会安全去重，不制造无限副本。
- 同一旧来源的新修订只更新自己的投影，不同旧来源即使 sourceId 相同也保持独立。
- 重复迁移和重复查询保持幂等；旧表修订变化后只刷新对应来源。

### 🎨 体验优化

- 知识列表保留原有标题和正文可读性；来源身份差异通过稳定投影 ID 和冲突元数据处理，不打断日常检索。

### ⚠️ 其他变更

- 需要 Node.js 24.9 或更高版本；当前适配官方 Desktop 0.2.2-rc.1。
- 本版未执行真实付费模型 A/B，不宣称模型效果领先。
- 本版未发布，也未提交 Git。
