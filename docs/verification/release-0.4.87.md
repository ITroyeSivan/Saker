## 官方桌面实测

使用实际桌面发布包中的安装器，通过应用自带官方命令安装全部插件，并检查安装文件内容。安装器从不同于源码的新目录运行，仍沿用现有快捷方式、工作目录和日常用户数据。设置文件更新前后 SHA-256 一致。

实际双击桌面的 **Saker (dsh Desktop)** 快捷方式启动应用，没有启用浏览器调试端口，也没有登录操作。新任务保持 Saker 渗透测试入口，常规、Nday、0Day 三个按钮均可切换；模型显示 Low。

插件页显示 25 个已安装包。MCP、漏洞情报更新和知识库设置均加载正常，未见插件激活错误或空白页面。情报更新保留此前 CISA 的 1,733 条完成记录，知识包显示 23/23。

Burp、Yakit 两份配置仍在且已启用。对应服务没有启动，因此显示已连接 0、可用工具 0；这不表示配置丢失，本轮没有运行其业务工具。前一轮无害 MCP 实际调用见[功能复测](desktop-healthcheck-2026-10-04.md)。

本版发布复测只检查安装、启动和界面；没有发起真实目标请求或新模型任务。三个方向的模型流程、任务停止、预算、子代理回收和成果导出沿用[前一轮桌面证据](framework-desktop-2026-10-03.md)，没有把此前用量重新标成本版数据。

## 发布内容

README、安装说明、插件清单与首页功能图已更新。GitHub 上原有 8 个历史发布的说明全部重写并逐条回读核对，原标签、附件和发布时间保留；原文在工作区另行备份。

桌面 ZIP 包含 25 个 tgz、安装器、必要包文件、文档与 SHA-256 清单；包文件用于安装后的内容核对，不包含用户配置、登录数据或依赖目录。源码中的凭据模式检查仅命中已有脱敏测试和文档规则示例。

当前验收基线限于 Windows Desktop 0.2.0-rc.2。安装期间官方命令仍提示部分 peer dependency 版本范围告警，未使用兼容性豁免。其他宿主版本、真实站点检出率及所有外部服务的完整业务功能尚未由本轮验证。
