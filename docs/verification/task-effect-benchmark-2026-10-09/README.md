## 官方 Desktop 实际结果

在 `_ref/tmp` 启动 p1 合成靶场，给官方 Desktop 的渗透会话明确两轮四角色对照步骤。真实模型读取 brief、设置任务、写本地 HTTP 脚本并执行，发出 8 个请求；随后提交实际响应中的回执 ID。[独立评分](score.json)为：私有读取成立、8 个请求、错误确认 0、对照及正文依据有效。[靶场审计](lab-audit.json)与[模型提交](submission.json)保留实际结果；全部账号、对象与标记是本次随机生成的合成练习数据。

使用官方 Desktop 调试接口选中实际会话并读到“已完成”及 8 个回执；没有代登录、MCP 或子代理。没有把模型的“已确认”文字直接当成评分。

这次有步骤指引，且走原生 pwsh 客户端，并非三组同工具实验；文件隔离、预算校准和全组随机运行未完成。因此不算 G1 完成，也不作为新版优于旧版或普通 Agent 的证据。
