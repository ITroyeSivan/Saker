# 任务参数与完成状态 Desktop 验收

运行版本：Saker 0.4.94 候选、dsh-redteam-results 1.0.44；官方 Windows Desktop 0.2.0-rc.2，使用原日常配置与用户数据。

## 修复与可证伪检查

任务开始支持独立字段及枚举，兼容旧 policy JSON但禁止混用；进度JSON与独立完成标记合并，同名冲突拒绝更新。原有方向、流程、人数、额度和不可重置约束继续生效。修复成果模块首次直接导入时，数据库schema在循环模块尚未初始化前引用回执schema的错误；建库语义未变，schema在打开数据库时构造。

6组真实注册工具检查通过；4个机制回退分别使启动、完成标记、首次导入或成果恢复契约检查失败，生产文件未被反向检查改写。官方宿主编译器接受20个实际任务及成果工具的schema；没有用自制schema校验器替代宿主。

最终完整回归89套、13,626通过、0失败、16跳过；85个必需套件均存在。之前的工具说明超预算和README与tgz不同步失败保留在工作记录，精简说明和重打包后最终回归通过。文档覆盖24个插件且版本一致。

## 第一轮官方 Desktop 结果

与0.4.93冒烟使用同一段562字提示词、同一模型和新建随机本地靶场。实际模型首次调用start即成功，未猜测mode/workflow。随后执行两轮四角色对照，共8个HTTP请求。[独立评分](score.json)通过，错误确认0；[原始审计](lab-audit.json)保留实际正文。progress使界面显示“本轮已完成。保留资料，设置下一轮”，完成状态确实持久化。

界面54秒、9步。[实际模型用量与调用](desktop-costs.json)累计231,424 token，其中非缓存输入20,010、输出8,406、缓存读取203,008；工具41个，定义36,287字节。对比上一轮15步、331,124 token只能说明此次有指引接入冒烟的变化，不能证明稳定效果或货币成本改善。工具描述随后精简到5,950字节，低于原有6,000字节门禁；未提高门禁额度。[工具头](desktop-tool-header.json)来自精简之前，不是最终wire请求体。

## 保留的失败和限制

第一轮模型两次调用finding_register都将编号式文本填入要求完整方法JSON的reproduction字段，收到原始JSON解析错误，成果未登记成功。精简工具说明后的复测又出现11次登记失败，20次模型响应累计686,655 token（非缓存输入24,799、输出23,264、缓存638,592）。模型自述只有9次失败，文档按宿主实际调用纠正；[失败轮用量](final-before-recovery/desktop-costs.json)完整保留。本轮控制程序未保持可写stdin，无法取得评分审计，已结束所属进程；它只能作为接入成本及错误证据，独立评分未知，不能记为通过。

据此同批增加完整恢复契约，保留原始错误和全部验证规则。再次使用相同提示词，模型经历一次编号文本错误、一次Invalid URL后，第三次调用成功登记。[恢复轮独立评分](recovery/score.json)通过，实际8个请求、错误确认0；成果页实际显示该条成果，已验证数仍为0，保持pending。界面显示67秒、12步；[宿主逐次用量](recovery/desktop-costs.json)累计317,257 token（非缓存输入12,284、输出11,341、缓存293,632），[原始靶场审计](recovery/lab-audit.json)保留。比较231K、687K、317K这些有指引轮次不能得出稳定节省结论。

成果登记成功不代表成果交付完成。宿主执行回执、独立影响验证和交付条件仍须单独满足；尚未跑这条完整链路。成果页的“本轮”成本统计从成功开始任务后计量，包含此前准备及失败开始的整段会话实际用量以transcript为准，全树预算契约仍待G5完成。

[最终实际桌面状态](desktop-final.json)：任务完成、成果页有pending记录，三个相关插件active。更新后实际启动桌面快捷方式，仍使用原日常home与userData，再通过官方调试接口验收。实际MCP设置保留2个启用服务器，但Burp/Yakit均unreachable、连接0、工具0；没有把已安装视为已连通。

本次没有完成三组随机效果评测、盲测文件隔离、全树token/请求预算或高并发验收。原生截图接口报“foreground window did not report a process id”；实际界面通过官方Desktop调试接口操作并读取，不声称取得原生截图。所有练习账号、对象、标记均为合成数据。测试进程和临时工作目录收工清理；Desktop自身在日常home写入的这些验收会话保留，不删除用户会话存储。
